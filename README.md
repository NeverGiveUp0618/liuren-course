## 改内容的流程

```bash
python3 build.py && node smoke.js        # 构建 + 冒烟
python3 _tools/_verify_cite.py           # 引文逐条回查原书页码
```

### 屏

首页 / 课程（25 课含待写占位）/ 课文 / **速查** / 学习路线 / **起盘台** / 搜索。

**⭐ 吸顶盘（六壬不能照搬八字四柱）** —— 四柱是 2×4，压成一条钉在顶栏下只占 60px；
六壬方盘是 4×4 的 330px 见方，照搬会吃掉半个屏幕。所以**吸顶的是四课＋三传**
（讲解里指代的几乎都是这些：发用／支上神／日上神／中传），约 44px，
**点这条弹出完整方盘**。⚠️ 纯 CSS `position:sticky`，绝不加"滚过才显示"的开关。

**课内目录** —— 一课上万字，用的是 `data-course.js` 里每课已存的 `heads`（h2 列表），
不另存一份。⚠️ 目录与「全盘」共用同一个浮层，两边都各自重建整块内容——
早先目录容器写死在 html 里，点过全盘后它就被覆盖掉，再点目录直接崩（已被 smoke 锁住）。

**速查** —— `build.py` 把各课正文里的 123 张表自动抽出来按课归档，
表本身仍只长在课文里（内容源一处），这里只是换一种检索方式。
表名取表格上方的小标题／引导句；**天地盘、四课、三传按结构特征直接命名**
（同一节里三张盘若都取上方那句引导语，会出现三个同名条目）；同课重名的加①②③。

`smoke.js` 需要 jsdom：`npm i --no-save jsdom`（没装会自动借用 ../bazi-course/node_modules）。

⭐ **起课引擎穷举**：12 月将 × 12 占时 × 10 日干 ＝ **1440 种组合**全部验一遍
（天盘必须是整体平移且月将落在占时位上；贵人落点正确、十二将不重不漏、顺逆与地盘位相符）。

## ⭐ 三个自检脚本，改完内容一定要跑

| 脚本 | 查什么 | 抓到过什么 |
|---|---|---|
| `_tools/_verify_cite.py` | 每条「」引文回原书 OCR 按页核对（**三册**、跨页、跨脚注都认，并顺带验两个页码的换算关系） | 累计抓到 **9 处页码错标**、**一处给引文私加了"地盘"二字**、**一处引了 OCR 讹字** |
| `_tools/_audit_pan.py` | 两层：内置 case 复算比对 ＋ **扫描课文里每一张盘**验证自洽（天盘必须是整体平移、天将必须自贵人起连续顺/逆） | 当前 10 张盘 0 处不符 |

| `_tools/_audit_content.py` | 结构（标题层级/表格配平/引文有无出处）＋**领域断言逐条验算**（寄宫·昼夜贵·支神名·五行生克·刑冲害破·驿马·旬空·日禄·五行墓·天将配干支，全用六壬本体系口径）＋交叉引用（wiki 死链、下一课是否连贯）＋**正文叙述 vs 盘面数据** | 见下方「2026-08-23 全量排查」 |

⚠️ `_audit_content.py` 报出来的**不一定是错**（正文常有"某说""存疑""反例"），逐条人工判读，**绝不照单全改**；
最灵的信号是**同一件事在两处说法不一致**。它自带 `--selftest`：喂 12 类坏数据，必须全报得出来。

⭐ 一个只会打印通过的脚本毫无价值。`_verify_cite.py` 的价值就在于它**真的报过错**；
改了检查逻辑，先确认它对已知的坏数据仍会报警。

## 2026-08-23 全量排查（做完一次，问题与结论记在这）

**发现的最大问题是校验本身有盲区**：

1. **表格里的引文从没被核过** —— `_verify_cite.py` 只扫 `>` 引用块，而第 8、9、12、20 课的骨架表**整表都是引文**（44 条）。
   扩展覆盖后立刻暴露 **3 处页码错标**（23 课词讼引文 p112→p107；12、20 课表格里写「同上」造成的归属歧义）。
2. **繁简盲区** —— 原书「傳送」一节 OCR 出来是繁体，教材用简体，直接比对会全判成"未找到"。已加繁→简归一。
3. **页眉污染** —— 跨页引文被整行页眉「大六壬通解」劈断。已过滤。

**据此修掉的内容问题**：11 处引文与原文有出入（漏字、把两句拼在一起没标省略号、把我的补注写进了引文）、
2 处原书讹字改为校勘注（「戊地狱」当作「戌地狱」、「人干」当作「入干」）、9 处「同上」展开为明确出处、
4 处「从右往左」统一为「从右到左」、总目录补上「」的标记约定。

**逐项验过没问题的**：25 课必备元素齐全；自测题数＝答案数（25/25）；跨课口径一致（昼夜分界、贼克优先级、
中末传通例、中气换将、五行墓、驿马表、天将次序、四课方向）；术语无异体混用；10 张盘自洽且与正文叙述相符；
引文 278 条逐条回原书全中。

## 出处口径

`〔通解上 p21｜PDF p36〕` —— 前者是**书内印刷页码**，后者是 **PDF／OCR 校对稿页码**。

⚠️ **三册的换算各不相同**（已用章节标题核对过，`_verify_cite.py` 每条都会验）：

| 册 | 换算 | 核对依据 |
|---|---|---|
| 上 | 书内 ＝ PDF **− 15** | 第一节历史起源 目录 p3 ↔ PDF 18 |
| 中 | 书内 ＝ PDF **+ 364** | 第二节六壬毕法赋 p487 ↔ PDF 123 |
| 下 | 书内 ＝ PDF **+ 732** | 第七章大六壬外编 p1067 ↔ PDF 335 |

OCR 校对版在 `马老师项目/大六壬笔记提炼/`，另有按课程目录重排的初/中/高级教材在
`马老师项目/南南-大六壬教材项目/`。

## 三种盘会被渲染成真盘（mdlite.py）

markdown 里这么写，就会渲染成盘而不是表格：

| 写法 | 渲染成 |
|---|---|
| `\|地盘\|子\|丑\|…\|亥\|` ＋ `\|天盘\|…\|` ＋ `\|天将\|…\|` | 方形式盘（外圈十二格的位置＝地盘） |
| `\| \|第四课\|第三课\|第二课\|第一课\|` ＋ 天将/上神/下神 | 四课盘（**从右到左**，最右是第一课） |
| `\| \|传\|遁干\|六亲\|天将\|` ＋ 初传/中传/末传 | 三传竖列 |

认不出的（缺行、地支不合法、原书没给全的占位表）**退回普通表格，不硬套**——
一眼能看出这里原书就是缺的。四课与三传里的干支按五行上色，方盘不上色（十二格全彩反而看不清）。

## 三个坑（照其余几个 App，别拆）

1. **history 路由包装** —— 套壳 `view.html` 的 iframe 与顶层共享同一条 session history。
   若本站不碰 history，读到课文深处一次侧滑会直接退出整个 App 回导航首页。
   `show()` 前进时 pushState，回到栈上已有的屏用 `history.go(-n)` 折叠，
   `popstate` 只移动指针**绝不截断栈**（截断会让 forward 找不到原来那屏，smoke 有断言锁住）。
2. **`wst-frame-guard`** —— iframe 内给 `<html>` 加此 class，隐藏自带返回入口，交给套壳顶栏。
3. **sw.js 网络优先 + 按需加载带 `?v=`** —— 微信 X5 内核缓存极顽固，会无视 `?query` 按路径缓存。
   `data-course.js` 是按需加载的大文件，**必须带 `?v=`**，只 bump sw 版本救不了它；
   sw 离线回退要 `ignoreSearch: true`，否则换了版本号就全部落空。
