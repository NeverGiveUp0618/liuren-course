## 一、取象法则

> 共 **106** 条，29 组。出处：《图解六壬大全》第 1、2 部

### 取象原则

**神煞主次法**

- **要点**　四课三传为骨架，神将为主象，神煞用来定应事的细节和应期。
- **怎么用**　先定日辰、发用、三传和问事类神，再看神煞是否并临七处。神煞单见且休囚空亡，不宜越过课传主象下重断。

〔出处〕《图解六壬大全》第1部·神将与神煞

**象法总纲**

- **要点**　神将地支比拟万事万象，取象必须服务于所占之事。
- **怎么用**　先定事体，再取相关类神；类象只作参考，不可照搬。凶将吉将、旺相休囚、课体喜忌要合看，目标是做到“式事合一”。

〔出处〕讲义上册·神将类象的意义

**凡有其象必有其事**

- **要点**　课中出现明确象意，往往对应现实事件。
- **怎么用**　不要孤立抓一个字断事。必须同时满足事体相符、类神入位、神将配合、旺衰有力，才可下重断。

〔出处〕讲义上册·神将类象的意义

### 应期

**发用管期**

- **要点**　发用所值时间层级，可定事情应验的大致范围。
- **怎么用**　太岁发用应年内，月建应月内，月将应日躔内，四季支应季内，旬首应旬内，当日支应当日，正时发用应当时。

〔出处〕《图解六壬大全》第1部·克应

**初合末冲定成散**

- **要点**　初传所合可作成事之期，末传所冲可作散事之期。
- **怎么用**　谋成、会合、交易可候初传之合；解散、脱离、冲开可候末传之冲。须同时校验类神旺衰和空墓，不可机械套日期。

〔出处〕《图解六壬大全》第1部·克应

**应期取法**

- **要点**　应期可从初传、末传、类神、冲合、填实、出空、旺相之期取。
- **怎么用**　急事看发用和正时，缓事看三传归宿和类神旺期；空亡事常待填实，墓闭事常待冲开。

〔出处〕讲义上册·判断入门

**填实出空**

- **要点**　空亡不是永远无事，出旬或遇岁月日填实可发动。
- **怎么用**　鬼空暂不凶，财空暂不得，人空暂不见。何时填实，常是事情显发或旧象复动的时间点。

〔出处〕讲义中册·家宅例

**冲开墓库**

- **要点**　墓库闭塞，逢冲可开。
- **怎么用**　占病墓重防闭塞沉重；占财库逢冲可能开库得财，也可能冲散库藏，须看财是否旺、有无救护。

〔出处〕讲义上册·八煞九宝

**合处成事**

- **要点**　合主牵连、和合、成就，也主绊住。
- **怎么用**　婚姻交易喜合，逃亡疾病忌合。合类神者即牵涉人，合处逢冲则关系破开。

〔出处〕讲义上册·八煞九宝

**冲处发动**

- **要点**　冲常为动机和应期。
- **怎么用**　静事逢冲而动，动事逢冲而散。冲日应我动，冲支应彼动，冲初末传应事情节点。

〔出处〕讲义上册·八煞九宝

### 旺相休囚

**发用旺衰定事**

- **要点**　旺气、相气、死气、囚气、休气、墓气发用，各有主事侧重。
- **怎么用**　旺气多主求官任职，相气主经营财货，死气主丧孝，囚气主刑讼，休气主疾病，墓气主淹延闭滞。再以所问事类神校正。

〔出处〕《图解六壬大全》第2部·克应断法

**旺衰校正**

- **要点**　吉将囚休不尽吉，凶将旺相不尽凶；凶将囚休，凶事反重。
- **怎么用**　同一类象必须看月令、日辰、旺相休囚死。旺相为有力、显著、可成；休囚为弱、迟、暗；死绝为空耗、断绝。

〔出处〕讲义中册·物类课

**旺相休囚死实用**

- **要点**　旺为盛大，相为进步，休为废气，囚为受制，死为结束。
- **怎么用**　断应期和力度时先看旺衰。旺相象强且快，休囚象弱且慢，死绝多主不成、衰败或只留痕迹。

〔出处〕讲义上册·五行

**生而不生**

- **要点**　生旺太过，福中藏祸；逢生不生，必成凶咎。
- **怎么用**　表面受生，若被空亡、刑冲、墓绝、凶将破坏，生意不能落实。不要见生就断吉。

〔出处〕讲义上册·五行

**死而不死**

- **要点**　死绝太过福无可托；但绝处逢生，先凶后吉。
- **怎么用**　类神入死绝而得长生、德合、贵人、救神，可断困中有转机；若救神亦空，则难救。

〔出处〕讲义上册·五行

### 八煞九宝

**合入传迟成**

- **要点**　合入传多主谋事有成，但合也主牵绊，往往不能立即了结。
- **怎么用**　婚姻、合作、交易喜合；疾病、词讼忌合，因病邪绵延、讼事缠绕。合神空破则约束无实，合处逢冲则可解。

〔出处〕《图解六壬大全》第1部·德煞·合神

**暗合主隐藏**

- **要点**　暗中三合、六合，常主失脱之物被隐藏、人事暗中牵连。
- **怎么用**　占失物要并看太阴、玄武、墓库和类神落宫；暗合得地则藏得深，被冲破或空亡则藏象不实。

〔出处〕《图解六壬大全》第1部·德煞·合神

**鬼入传取救**

- **要点**　占讼、占病忌官鬼入传临日，子孙为制鬼救神。
- **怎么用**　鬼旺克日而无制，官灾病势偏重；子孙旺相入传或临年命，可减凶解厄。救神空亡受克，则有救名而无救力。

〔出处〕《图解六壬大全》第1部·鬼煞

**八煞总纲**

- **要点**　刑、冲、破、害、墓、鬼、败、空，是六壬判断中最常用的凶性关系。
- **怎么用**　八煞不单独断吉凶，要看所临类神为何物、是否入七处、是否旺相、有没有德合救制。类神遇八煞，多表示该类事物受伤、阻隔、散失或落空。

〔出处〕讲义上册·八煞九宝

**刑象**

- **要点**　刑主伤损、拘束、刑禁、互相折磨，也有自刑、无恩之刑、恃势之刑等差别。
- **怎么用**　占病见刑，多主痛、伤、血、手术或病势反复；占讼见刑，主刑名官禁；占人事见刑，主彼此不顺、相逼相损。

〔出处〕讲义上册·八煞九宝·刑

**冲象**

- **要点**　冲主动摇、冲散、变动、远离、相反相攻。
- **怎么用**　吉事逢冲多不稳，凶事逢冲可解散。看冲谁：冲日为动我，冲支为动彼/宅，冲类神则该事发生变化。

〔出处〕讲义上册·八煞九宝·冲

**破象**

- **要点**　破者，散也、移也、破损也。
- **怎么用**　财见破为破财，物见破为破物，婚合见破为约散，文书见破为不行。破不一定大凶，也可表示凶事破散。

〔出处〕讲义上册·八煞九宝·破

**害象**

- **要点**　害主暗损、隔碍、彼此不和，常不如冲刑显露。
- **怎么用**　占婚姻、合作、家宅，见害多主暗中不合、亲近处相伤；害类神而又空亡，常有虚害、误会、拖延。

〔出处〕讲义上册·八煞九宝·害

**墓库分辨**

- **要点**　生处为库，死处为墓；库可藏财藏事，墓多闭塞埋没。
- **怎么用**　占财见库可作收藏、积蓄；占病见墓多主沉重闭塞；占人见墓，主困、伏、藏、不能伸展。墓上逢虎鬼则凶重。

〔出处〕讲义上册·八煞九宝·墓

**鬼象**

- **要点**　克日者为鬼，主压力、病灾、官非、惊惧、约束。
- **怎么用**　鬼临日干多应身上压力，鬼临支宅多应家宅不宁；鬼空可暂无畏，但填实、出空时仍会发动。

〔出处〕讲义上册·八煞九宝·鬼

**败象**

- **要点**　败主沐浴、败坏、耗散、色欲、事体不正。
- **怎么用**　占财见败，财散不聚；占婚情见败，主桃色、暧昧、失礼；占病见败，气血虚耗或久病难收。

〔出处〕讲义上册·八煞九宝·败

**空亡取象**

- **要点**　空亡主虚、无、迟、脱节、落空；吉空则吉减，凶空则凶轻。
- **怎么用**　类神空，多主该事未实、无力、找不到、暂不发生。若出旬填实，原来伏着的象会再动。

〔出处〕讲义上册·八煞九宝·空

**德合救制**

- **要点**　德、合、贵、禄、马、旺、奇等可缓和凶象，也可加强吉象。
- **怎么用**　断凶时先看有没有救神，断吉时要看吉神是否有力。德合生扶类神，事情有缓和、转圜、贵助、和解之机。

〔出处〕讲义上册·八煞九宝

### 神将组合

**天后神后合婚**

- **要点**　天后、神后为女性婚姻要象，与合神同见，婚约之象更显。
- **怎么用**　后、子、合入课传而旺相生日，可作婚事易成；若又逢空、破、绝、刑害，则只有议婚之象而难成。

〔出处〕《图解六壬大全》第1部·合神

**三合局性**

- **要点**　三合不只言合，四局各有性情：木局繁杂，金局改革，火局党侣，水局流动。
- **怎么用**　亥卯未多繁冗驳杂；巳酉丑多矫革离异；寅午戌多党侣结众；申子辰多流动无滞。问事吉凶仍看局神对日干和类神的生克。

〔出处〕《图解六壬大全》第1部·支合

**将神再忌刑冲**

- **要点**　天将给地支类神加属性，若将神又遭刑冲，其主象多受损或显露。
- **怎么用**　例如贵人受克防贵嗔，螣蛇逢刑防火怪惊忧，龙合受破防财婚不成。先说清被伤的是哪一个类神，再落具体事。

〔出处〕《图解六壬大全》第2部·课体总论

**天将破象**

- **要点**　破主散、移、破损；不同天将遇破，所破之事不同。
- **怎么用**　贵破则贵助废，蛇破则牵连不允，雀破则文书口舌不行，合破则婚姻交易不成，龙破则财喜文案不成，武破则盗谋不成，后破则恩泽婚姻不来。

〔出处〕讲义上册·八煞九宝

### 发展观

**内外传取求索**

- **要点**　三传由内向外，多主我方外求；由外入内，多主彼方来索。
- **怎么用**　占求人、求财、交易时，传出支宅、趋向干外，常是我有所求；传入日辰宅内，常是他人来求或事物归身。

〔出处〕《图解六壬大全》第2部·课体总论

**生旺墓绝传化**

- **要点**　三传从墓绝走向生旺，多先难后易；从生旺走向墓绝，多先吉后凶。
- **怎么用**　动态趋势比单看初传更重要。初传虽凶，末得长生帝旺可转好；初传虽吉，末入墓绝应防结果败坏。

〔出处〕《图解六壬大全》第2部·重审课

**末传收束法**

- **要点**　末传是事势归宿，末得吉将、德神、月德等扶助，常能化凶。
- **怎么用**　断课不在初传便停下。初凶末吉可断有救、后遂；初吉末凶须防晚败。末传空亡、入墓或被克，结果往往不落实。

〔出处〕《图解六壬大全》第2部·课体吉凶

**初中末三传**

- **要点**　初传言事之始，末传决事之终。
- **怎么用**　初传凶而末传吉，先难后遂；初传吉而末传凶，先成后败。初末皆吉则始终吉，初末皆凶则始终难。

〔出处〕讲义中册·物类课

**三传进退**

- **要点**　三传顺进多主进展、推进、渐成；逆退多主退缩、复旧、反复。
- **怎么用**　进传宜进，退传宜退；若进传逢空，进而不实；退传逢救，可退中保全。

〔出处〕讲义中册·课体象法

**连茹取象**

- **要点**　三传相连，事情连续牵引，常一事带一事。
- **怎么用**　连茹用于断行人、事情进程、牵连关系。传向日辰或宅，多主事情归身归宅；传向空亡，多主中途断落。

〔出处〕讲义中册·连珠/间传

**间传取象**

- **要点**　间位作三传，主中间隔碍、进退有节、一步一转。
- **怎么用**　断事不可只看初末，中传往往是关键关节。间传吉凶随阴阳进退与所乘神将细分。

〔出处〕讲义中册·间传

### 综合取象

**合局分局**

- **要点**　合局主事从众起，分局主分劈零散。
- **怎么用**　多人合作、党侣、群体事见合局，常非一人所为；课传冲散、各不相就，则事情拆分、意见不一。必须看聚众是生我还是克我。

〔出处〕《图解六壬大全》第2部·课体总论

**重叠交互**

- **要点**　神将重叠主同类事反复发生，上下交克主往复无定。
- **怎么用**　同象在四课三传多处重现，才可将该象加重；交互克战时，事情多反复、彼此制肘，不宜只取某一处吉凶。

〔出处〕《图解六壬大全》第2部·课体总论

**物以声应 方以类萃**

- **要点**　六亲、五行、神将、地支同类互相牵引。
- **怎么用**　见父母爻可推长上、文书；见财爻可推妻财、产业；见兄弟可推同类争财。再以神将吉凶、旺衰和刑冲破害细分吉凶。

〔出处〕讲义中册·物类课

**新旧生死**

- **要点**　生旺可作新、生物、正在发生；死墓可作旧、故物、已衰败。
- **怎么用**　占物、占宅、占病时，看类神所临五行状态。生处为库，死处为墓；库可藏可成，墓多闭塞衰滞。

〔出处〕讲义中册·物类课

**聚散取舍**

- **要点**　得令得气为聚，失令无气为散。
- **怎么用**　当象太多时，用五行得气、遁干、生克趋势来取舍主象。聚则事集中、有力、成局；散则力量分裂、难成、易改。

〔出处〕讲义上册·判断入门

**物类课法**

- **要点**　六亲俱现，以用为主；旺相吉言，休囚凶语。
- **怎么用**　同时出现多类人事时，先抓发用和问事类神。用神为父母则文书长上，用神为财则妻财产业，用神为兄弟则同类竞争。

〔出处〕讲义中册·物类课

**神将分取始终**

- **要点**　始终吉凶，神将分取。
- **怎么用**　初传神将主开端气象，末传神将主结果归宿。初凶末吉可转好，初吉末凶防后败。

〔出处〕讲义中册·物类课

**类象组合句法**

- **要点**　地支是实体名词，天将是状态属性，二者相乘生成具体象。
- **怎么用**　如酉为鸡鸟金玉，乘白虎可成刀伤宰杀，乘朱雀可成能言飞禽，乘太阴可成妇女私物。

〔出处〕讲义上册·神将类象

### 日辰发用

**日辰为两仪**

- **要点**　日为人、我、外、动；辰为宅、彼、内、静，两者是占断宾主之根。
- **怎么用**　先看日辰谁旺谁衰、谁生谁克，再看各自上神和阴神。问事不同可改取类神为体，但日辰仍是主客背景。

〔出处〕《图解六壬大全》第2部·日辰

**发用为事端**

- **要点**　初传发用是事物发端、来意切口和最先显现的动机。
- **怎么用**　看发用的六亲定事类，天将定性质，所临地盘定环境，旺衰空墓定真假力度，中末传定发展和结局。

〔出处〕《图解六壬大全》第2部·发用

**日辰上神交互**

- **要点**　干上加支、支上加干，可见人宅、彼此的就近、投就和求索。

### 三传组合

**三传递生**

- **怎么用**　看哪一传得时得地，哪一个类神为主导。若克制凶鬼为有救，若克制财官长生则成功条件受损。

### 类神规则

**类神显隐**

- **要点**　类神入课传为显，入本命行年次之，俱不入则为晦。
- **怎么用**　占文书看朱雀，占见贵看天乙，占惊怪看螣蛇，占婚男看青龙、女看天后。类神不出现，不等于没有其事，常表示事情隐伏、间接或未到显发处。

〔出处〕讲义上册·神将类象的意义

**七处定位**

- **要点**　日、辰、初传、中传、末传、本命、行年，是判断类神的关键位置。
- **怎么用**　类神入七处，重点看落宫、所乘神将、刑冲破害、旺相休囚、空亡与是否当令。七处以外的类神，可先看它与阳神、日辰之间的关系。

〔出处〕讲义上册·神将类象的意义

**阴神取象**

- **要点**　类神有阳神、阴神两面，阴神是其内情、根由、背后状态。
- **怎么用**　看类神本身之外，还要看其阴神与阳神、日辰的生克。占人事常用阴神推背后的人、隐情、真实原因。

〔出处〕讲义上册·神将类象的意义

**直接类神不看六亲**

- **要点**　部分十二支类神可直接取其本象，不必先按日干六亲转义。
- **怎么用**　如子可直取子息、水物，酉可直取鸡鸟金玉，申可直取道路行人。若类神又临凶将、入传、受克，象意更实。

〔出处〕讲义中册·家宅例

### 断课入口

**体用与太极点**

- **要点**　六壬占人事，要先确立太极点，再分彼此、体用、内外、宾主、尊卑。
- **怎么用**　常规以日干为我/人，日支为彼/宅/事；不同问题可改用类神、本命、行年、初传为体。体用错，象法会全盘跑偏。

〔出处〕讲义上册·判断入门

**日辰内外**

- **要点**　日干偏人、主、阳、外显；日支偏宅、彼、阴、承载。
- **怎么用**　占婚可分男女，占宅以支为宅，占人以干为身。干支上神、干支阴神，是主客双方的直接状态和后续变化。

〔出处〕讲义上册·判断入门

**四课阴阳**

- **要点**　日阳、日阴、辰阳、辰阴，是主客双方的显面与隐面。
- **怎么用**　第一课看我方表面，第二课看我方内情；第三课看彼方/宅表面，第四课看彼方/宅内情。

〔出处〕讲义上册·起四课

**日干寄宫**

- **要点**　天干须寄于地支宫位，才能进入天地盘取象。
- **怎么用**　干上神是日干当前处境；干阴神是其背后发展。占自身、事业、病体，日干两课尤重。

〔出处〕讲义上册·起四课

**支上定宅事**

- **要点**　支为宅、彼、事体承载处，支上神是外部环境或对方状态。
- **怎么用**　占家宅、失物、婚姻、交易，支上神与支阴神常是关键。支上克干，多主彼方压我或宅气不利。

〔出处〕讲义下册·家宅例

**正时取象**

- **要点**　占时是起课动机，也是当下触发点。
- **怎么用**　时上神、时上天将可辅助来意、应期和事件触发。占当日事、天气、行人，正时尤其有用。

**本命行年**

- **要点**　本命切终身，行年切当年当下之人。
- **怎么用**　课中不见财官，可看命年上财官。命年入课传或与类神相合，事情更贴身；受克空亡则本人无力或不应。

### 取象戒法

**不可一端泥象**

- **要点**　象者，像也，像则无物不该，不能只按一个固定含义套断。
- **怎么用**　同一课象在平常事可作宾主相投，在兵贼事可作围困交结。取象必须随事体切换语境。

〔出处〕讲义中册·案例附议

**来意约束取象**

- **要点**　来问者身份、问题场景，会约束同一符号的落点。
- **怎么用**　老农来占，酉可偏麦产、田财；商人来占，酉可偏财货、交易；病人来占，酉又可落口窍、血精、肺金。

〔出处〕讲义中册·来意占例

**凶将不一概凶**

- **要点**　凶神吉将，不可一例而推。
- **怎么用**　凶将旺相有时反能成事，吉将休囚也可能无力。比如白虎可主武职、刀兵、急速；玄武可主水路、隐蔽、谋略。

〔出处〕讲义上册·神将类象的意义

**象随事转**

- **要点**　同一组合在不同问题里含义不同。
- **怎么用**　交车可作宾主相投，也可作重围交结；青龙可作喜财，也可作林木舟车；朱雀可作文书，也可作口舌火灾。

〔出处〕讲义中册·案例附议

**课体不可代替类神**

- **要点**　格局说明大势，类神落实具体人事。
- **怎么用**　见吉格不代表所问必吉，见凶格不代表所问必凶。必须看所问类神是否入局、是否有力、是否受伤。

〔出处〕讲义上册·判断入门

**事理约束**

- **要点**　断课要合现实事理，不可只凭字面强断。
- **怎么用**　年龄、身份、职业、来意、当时处境都会约束取象范围。越具体的象，越需要多重证据。

〔出处〕讲义下册·占验例
