# 第15课 · 三传怎么读：始中终与递生递克

> **本课解决什么**：三传不是三个孤立的字，而是**一件事的三段**。这一课教你把它们连起来读成一条走势。
> **前置**：[[14-主客内外体用·谁是我谁是对方]]
> **本课的一句话**：**初传定起点、中传定转折、末传定结果；再看三段之间是相生还是相克，走势就出来了。**

---

## 一、三传＝事情的三个阶段

> 「**初传代表事情的开始阶段，中传代表事情发展的中间阶段，末传代表事情发展的最后阶段**。然后根据它们**与日辰的生克关系**仔细判断。」
> 〔通解上 p137｜PDF p152〕

对应第 13 课的三门：

| 传 | 门 | 管什么 |
|---|---|---|
| **初传** | 发端门 | 事起于何——「**心之所主，事之所向，最为紧要**」 |
| **中传** | 移易门 | 中间的转换——初凶中吉即可转凶为吉 |
| **末传** | 归计门 | 最后的结果与归宿 |

---

## 二、⭐ 始终卦：古人四家怎么读三传

《通解》在毕法赋之前，专门辑了一节「始终卦」，四家说法叠在一起看，读三传的分寸就出来了。

### 《观月经》——最基本的四种组合

> 「诸卦推始终，此卦最为良。**初传为始位，末传是终乡**。**始吉兼终吉，万事太无妨。初凶末有吉**，从空喜并强。**始吉终不善，先喜后乖张。始吉终见破，遇克却馨香**。消息皆如此，论情道理长。」
> 〔通解中 p487｜PDF p123〕

| 初传 | 末传 | 断 |
|---|---|---|
| 吉 | 吉 | **万事太无妨** |
| 凶 | 吉 | 先难后成（喜从空来） |
| 吉 | 凶 | **先喜后乖张** |
| 吉 | 见破 | 遇克反而馨香 |

> 💡 原书对"初凶末吉"还给了具体判据：「**初传囚死刑害，天空朱雀，是初传凶**；末传见吉将三合、六合、青龙，主喜事从空而来也。」〔通解中 p487｜PDF p123〕

### 《心镜》——加上生克与神将

> 「始终之卦再临时，**神将相传为正义**。**始吉终凶终不善，先凶后吉庆相随**。善恶等分无咎誉，**首末俱吉福大奇**。**中末克初无不利，始往克末忧害身**。**三传相生万事成，若或相克为鬼贼**。」
> 〔通解中 p487｜PDF p123〕

> ⭐ 这里出现了本课的第二个重点：**三传之间的生克**。
> 「中末克初无不利」——后面克前面不要紧；「**始往克末忧害身**」——前面克后面反而伤身。

### 《袖中金》——救应

> 「论三传初中末，即事有创始，有成终，方为始终有全。**凡初传凶，终末吉，能解之。三传凶，行年吉，能解之。三传行年尽凶则凶不可解也**。」
> 〔通解中 p487｜PDF p123〕

> ⭐ **一条很实用的救应梯度**：初凶 → 看末传能不能解；三传全凶 → 看**行年**能不能解；连行年也凶，**才是真凶**。

### 《曾门》与《定章》——总纲

> 「始吉终吉，自穷于吉。始凶终凶，自穷于凶。始吉终凶，先吉后凶。始凶终吉，先凶后吉。**神将俱和，是为大吉。相克不和，名曰大凶**。」
> 「**神将俱和，如子归母为吉。神将不和，即仇怨为凶也**。」
> 〔通解中 p487｜PDF p123〕

## 三、用六亲把三段串成一句话

> 「假如**初传为官鬼、中传为父母、末传为妻财**，可以大概得出**先阻、中助、末得**的结论，更进一步在六亲变化之中细细分辨观察。这种方法很好，将事物的发展分为三个阶段，**从发展观的角度来判断事体未来发展**。」
> 〔通解上 p138｜PDF p153〕

**读法模板**：

```
初传六亲 → 中传六亲 → 末传六亲
  官鬼        父母        妻财
  先阻        中助        末得
```

| 六亲 | 在这一段意味着 |
|---|---|
| **官鬼** | 阻碍、压力、是非（占官则为职位） |
| **父母** | 助力、文书、长辈、庇护 |
| **妻财** | 财物、所得、妻 |
| **子孙** | 解厄、晚辈、下级；**能御鬼** |
| **兄弟** | 同辈、朋友；也主分夺、阻力 |

> ⭐ **把三个六亲连读成一句话**，这是六壬最快出结论的一招：
> 兄弟→官鬼→妻财 ＝ 先被分夺、中间遇阻、最后得财；
> 妻财→官鬼→子孙 ＝ 先得财、中招灾、终有解。

## 四、三传之间的生克：递生与递克

### 递生：三传俱生

**毕法赋第三十一法：三传递生人举荐。**

> 「此格有二等，一自**初传生中，中生末传，末传生日干**；一自**末生中传，中传生初传，初传生日干**。凡占值二例，**必隔三隔四有人于上位推荐之意**，所谓皆赖众人之说。如欲干官及请举文状，皆宜得之，**必得始终成就也**。」
> 〔通解中 p536｜PDF p172〕

> ⚠️ **但要先看空亡**：「惟宜详初末空亡，**如值空亡者，虽有举荐之心，终无成就之实**，乃便作闲话多、赤心少之语也。」〔通解中 p536｜PDF p172〕
> 原书举的例：辛丑日，三传卯→巳→未，未土生辛干，**中空末落空**——须待年月或干事人本命填实方成。

### 递克：三传互克

**毕法赋第三十二法：三传互克众人欺。**〔通解中 p537｜PDF p173〕

与递生正相反：三传彼此相克，主**众人相欺、四面掣肘**。

### 一张对照表

| 三传关系 | 断 |
|---|---|
| **递生**且末生日干 | 有人举荐，始终成就（⚠️ 忌空亡） |
| **递克** | 众人欺，处处受制 |
| **中末克初** | 无不利——后段克前段不碍事 |
| **初克末** | **忧害身**——前段克后段反伤自己 |
| 三传相生 | 万事成 |
| 三传相克 | 为鬼贼 |

〔通解中 p487、p536-537｜PDF p123、p172-173〕

## 四·B、⭐ 三传隔一位递进：间传二十四格

三传若是**隔一位**往前（或往后）走——辰→午→申、寅→子→戌这种——原书有专门的名目，叫**间传课**：

> 「凡课**间位作三传**，为间传课。此**顺间传十二格，逆间传十二格**，其义各有所主……盖间一位递作三传，故名间传。**占者顺主事顺，逆主事逆**。统『巽』之体，乃阴阳升降之课也。」
> 〔通解中 p473｜PDF p109〕

**先认顺逆，再查格名**——顺行主事情顺着走，逆行主事情倒着退，这一句先定大方向，比记二十四个名字要紧。

### 顺十二格（三传顺行隔一位）

> 「凡**巳午未申四位皆为天**，如间传遇**辰午申为登三天格**，盖龙登天则行雨，官登天位主迁转，惟忌空脱。」
> 〔通解中 p473｜PDF p109〕

| 三传 | 格名 | 断意 |
|---|---|---|
| 辰午申 | **登三天** | 官登天位主**迁转**、久旱得雨；争讼转大、占病症候加深。⚠️ 忌空脱 |
| 午申戌 | **出三天** | 亢龙有悔，事情远大；出行失约，病讼皆凶 |
| 申戌子 | **涉三渊** | 龙涉渊则不雨、贼涉渊则不来；病讼危险，眼前阻隔，占官不吉、谋望不成 |
| 戌子寅 | **入三渊** | 凡举皆凶，如履春冰、蹈虎尾，祸在前头。末传乘蛇虎作鬼煞者，病必死 |
| 子寅辰 | **向阳** | 自暗入明，**初凶后吉**；病愈讼解，人情皆美 |
| 寅辰午 | **出阳** | 灾咎相仍，病讼皆凶 |
| 丑卯巳 | **出户** | 访人不在、行人已出；利干望，君子升扬，小人狐疑不吉 |
| 卯巳未 | **盈阳** | 阳已至盈、物极必反——**急就则吉，拖延则凶** |
| 巳未酉 | **充盈** | 物满必缺、势过人衰，凡占皆凶；占官被黜。⚠️ 唯**久病反愈**、新病则死 |
| 未酉亥 | **入冥** | 明消暗长；事宜速办，缓则不及；病讼凶、官不利 |
| 酉亥丑 | **凝阴** | 严霜冰坚之象；多主淫欲奸盗、事情幽暗不明 |
| 亥丑卯 | **溟蒙** | 事体不真，忧惧不宁，进退未决 |

### 逆十二格（三传逆行隔一位）

| 三传 | 格名 | 断意 |
|---|---|---|
| 寅子戌 | **冥阴** | 自明入暗，凶暗在前，防暗损；**占官最凶** |
| 子戌申 | **偃蹇** | 以阴入阴，历涉艰难，重遭荆棘；行军被围，出入作为不吉 |
| 戌申午 | **悖戾** | 自深退浅、逃祸不能；行人未至、贼不来，作事成祸 |
| 申午辰 | **凝阳** | 阳凝在阴，灾还缠着；前事未了、行人来迟、讼留连、谋事迟 |
| 午辰寅 | **顾祖** | 子回顾母、复归旧庐——**求财谋望皆吉**，贼去人来，占官大吉。⚠️ 惟庚日占病凶 |
| 辰寅子 | **涉疑** | 涉历疑难、莫知深浅；进退不决，关渡防埋伏，不可举兵，官病皆凶 |
| 丑亥酉 | **极阴** | 阴退至极；多淫泆酒色奸乱，病主死，讼至省部 |
| 亥酉未 | **时遁** | 利隐遁潜形；行人不出、捕盗不获、贼去不来——**君子吉而小人凶** |
| 酉未巳 | **励明** | 历阴暗而后得明；凡举皆由勉强而后成，君子利取禄位 |
| 未巳卯 | **回明** | 缺月渐回；不可骤举、只宜迟进，久雨则晴，吉渐成而凶渐消 |
| 巳卯丑 | **转悖** | 避明向暗、弃正归邪；家零身怯，怪梦，好出头而不知守分 |
| 卯丑亥 | **断涧** | 一阳深入二阴、阳明断送；君子退职，小人遇凶 |

> 💡 **不必硬背二十四条**。这套名目的底子只有一句：**巳午未申为"天"、亥子丑寅为"地"（渊）**，三传往天上走就是登、出，往地下走就是涉、入；顺行往明处去多吉，逆行往暗处退多凶。名字忘了，照这条推也能说个八九不离十。

> ⚠️ **两个例外要记住**，它们正好反着来：**巳未酉充盈格「新病死、久病愈」**，**午辰寅顾祖格是逆行却大吉**（子回顾母、复归旧庐）。别被"顺吉逆凶"一句带偏。

### 顺带一提：什么算阳、什么算阴

原书老实交代了这套阴阳并没有统一口径：

> 「以上**阴阳各有三说**：或以昼为阳，夜为阴。或以子丑寅卯辰巳为阳，午未申酉戌亥为阴。或以子寅辰午申戌为阳，丑卯巳未酉亥为阴。」
> 〔通解中 p475｜PDF p111〕

> 〔存疑〕**三说并列，原书没有替读者选**。上面二十四格的取象用的是第二说（子…巳为阳、午…亥为阴，即以冬至夏至分阴阳升降）。遇到别处按另一说讲的，先看它用的是哪一套，别直接判它错。

## 五、别忘了三传与日辰的关系

三传内部读完，还要回到**日辰**（我与对方）：

> 「然后根据它们**与日辰的生克关系**仔细判断。以其自身的……**将神生克为正论**，以初建复建法为变通看法。如经所云：'**吉凶随神而变，将之吉凶随类而迁**。'」
> 〔通解上 p137-138｜PDF p152-153〕

**顺序**：

```
① 三传各自是什么六亲、乘什么将、旺不旺、空不空
② 三传之间：递生／递克／有无刑冲
③ 三传与日干、日支：生我／克我／我克／我生
④ 有没有救应：末传能不能解初传？行年能不能解三传？
```

> ⭐ **第④步最容易漏**。《袖中金》那条救应梯度就是给这一步用的。

---

## 六、⚠️ 四个坑

1. **只看初传就下结论。** 初传最紧要，但**末传才是结果**；初凶末吉能解。
2. **递生就断大吉。** 先查**空亡**——初末落空，"虽有举荐之心，终无成就之实"。
3. **把"克"一律当坏事。** 中末克初无不利；**初克末才忧害身**。方向要看清。
4. **三传全凶就断死局。** 还有**行年**这一层救应；行年也凶，才是"凶不可解"。

## 七、自测

**1.** 初传囚死又乘天空朱雀，末传乘青龙且入三合，怎么断？

**2.** 三传六亲依次是兄弟、官鬼、妻财，一句话说走势。

**3.** 三传递生、末传生日干，占请托举荐吉不吉？还要看什么？

**4.** 「中末克初」与「初克末」，哪个不利？

**5.** 三传都凶，还有救吗？

---

### 答案

**1.** 这正是原书说的**初凶末吉**：「初传囚死刑害，天空朱雀，是初传凶；末传见吉将三合、六合、青龙，主**喜事从空而来**」——先难后成，事情起头不顺但结果是好的。

**2.** 兄弟→官鬼→妻财：**先被同辈分夺（或起头有竞争），中间遇阻（官鬼为压力是非），最后得财**。

**3.** **吉**——毕法赋第三十一法「三传递生人举荐」，主有人在上位推荐，干官、请举文状皆宜，「必得始终成就」。但**必须先查初末有无空亡**：落空则只有举荐之心、无成就之实，要等年月或本命填实。

**4.** **初克末**不利——「始往克末忧害身」；**中末克初**「无不利」。

**5.** 有——看**行年**。《袖中金》：「三传凶，行年吉，能解之。**三传行年尽凶则凶不可解也**。」
