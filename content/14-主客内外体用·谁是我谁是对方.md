# 第14课 · 主客内外体用：谁是我，谁是对方

> **本课解决什么**：盘上哪个位置代表我、哪个代表对方、哪件事从外来、哪件事从内起。**分错了，后面全断反。**
> **前置**：[[13-七处与八门·先看哪几个位置]]
> **本课的一句话**：**日干为我、日支为彼；日为外、辰为内；地盘日为体、天盘日为用——先立太极点，再谈生克。**

---

## 一、先立太极点

> 「大六壬主管人事，在人事的预测中**要确立太极点**，就要涉及到多个方面……针对预测对象要区分**彼此、体用、内外、出入、宾主、尊卑**；在时空利弊上，要明**天时、知地利、喜忌、虚实、聚散**；在发展观上，要知**进退、动静、始终、迟速、存亡、胜负**……这样才能将六壬与人事真正意义上连接起来，达成'**式事合一**'而论。」
> 〔通解上 p130｜PDF p145〕

本课讲第一组：**彼此、宾主、尊卑、内外、体用**。

---

## 二、彼此：日干为我，其余为他

> 「**日干为自己，为我，为求测人；三传为他**，代表事情以及事情所涉及的他人。**地盘上的日为体**，为求测者本体；**天盘上的日为用**，为动态中的求测者本体……**其余四课三传都是他人**。」
> 〔通解上 p130｜PDF p145〕

| 位置 | 代表 |
|---|---|
| **日干** | 我、求测人 |
| 地盘上的日（干寄宫本位） | **体**——我的本体 |
| 天盘上的日 | **用**——动态中的我 |
| 日支 | 彼、家宅、所占之物 |
| 三传与其余各课 | **他**——事情本身与相关的人 |

> ⭐ **严格分彼我的价值**：「这样严格区分彼我，就可以很清楚地分析出**事情的发展对当事人的利与弊**，并且能够分析出事情发展中可能出现的人、物是怎样的状态。」〔通解上 p130｜PDF p145〕

### 干支还有一层层的类比

> 「**干为男子，支为女人；干为远为外，支为近为内**。这种种类比，都源出阴阳法则，即**日干为阳，日支为阴**。」
> 〔通解上 p130｜PDF p145〕

### ⭐ 干支在不同事体里代表什么（原书举例）

> 「如**占天雨**，以干为天，以支为所占之地；**占考试**，干为举子，支为场屋；**占求官**，干为求官之人，支为所历之任；**占谋事求财**，干为我，支为我所求之人；**占出行**，干为此处，支为彼处，余依此推。故每一课演成，**先省察干支上神，心中便有把握，然后详观三传，则事之始终定矣**。」
> 〔通解上 p131｜PDF p146〕

| 占什么 | 日干 | 日支 |
|---|---|---|
| 天雨 | 天 | 所占之地 |
| 考试 | 举子（考生） | 场屋（考场、考试本身） |
| 求官 | 求官之人 | 所历之任（职位） |
| 谋事求财 | 我 | 我所求之人 |
| 出行 | 此处 | 彼处 |

> 💡 **这张表是"太极点"的实操**：同一张盘，占的事不同，日支代表的东西就不同。**先想清楚"这件事里，谁是支"**，再看它的上神与生克。

## 三、日辰生克：十几种情形的读法

原书给了一首歌诀，把日与辰的各种生克关系读法收齐了。挑最常用的排成表：

| 情形 | 断 |
|---|---|
| **日上生日**（干上神生日干） | 百事吉；昼将得人助，夜将得神庇 |
| **日上克日** | 百不利；昼将主人害，夜将主鬼魅 |
| **日生上神** | 百费出（破费） |
| **日克上神** | 事抑塞；⚠️ 乘吉将则**妻利财获**，乘凶将则**财散妻灾** |
| 日辰各受上神**生** | 两家顺利有生意 |
| 日辰各受上神**克** | 两家俱伤都不利 |
| 日上脱辰／辰上脱日 | 我脱他／他脱我；各受上神脱则**彼此防脱俱蹉跎** |
| **日临辰上又受下克** | 名**乱首**——自取卑幼凌犯 |
| **辰临日上又克日** | 卑幼上门肆侵欺，亦名乱首，主父子兄弟各离析 |
| 日临辰上去受生 | 以尊从卑受包容 |
| 辰临日上来生日 | 彼自上门来周济 |
| 日临辰上去生辰 | **宅旺人衰**，虚耗频 |
| 日临辰上去克辰 | 事虽费力**得财** |
| 辰来临日受日克 | **尊长得财，卑幼悲**；此与上条皆名**赘婿** |
| 日上见**禄马** | 主荣迁；日见辰马主宅动（君子迁官，小人宅动） |
| **辰上见日禄** | 受屈抑，**权摄不正** |
| 日辰上各见**德神**乘吉将 | 进发真（可进取） |
| 日辰**乘墓坐墓** | 俱主昏迷云雾中 |
| 日辰互见**刑害** | **宾主不投怀猜忌** |
| 日辰逢**败** | 人宅颓 |
| 日课不足／辰课不足 | 心意焦／家宅忧 |

〔通解上 p131｜PDF p146〕

> ⚠️ 歌诀里的**鬼墓**要留意：「甲乙日丑，丙丁日辰，戊己日未，庚辛日戌，壬癸日辰。**日辰坐于墓为甘心自招暗，更甚乘墓**。」——这属于**暗鬼**，尤当防。〔通解上 p131｜PDF p146〕

## 四、内外：事从哪儿来

> 「**日为外，日阴也是外；辰为内，辰阴也是内**。外代表**事情从外而入**，内代表**事情从内部、自身引发**，**外为出**……」（末句原文作「内为□」，校对稿此处一讹字，意即**内为入**）
> 〔通解上 p131｜PDF p146〕

| | 位置 | 意义 |
|---|---|---|
| **外** | 第一课（干上神）、第二课（日阴） | 事从外来；出 |
| **内** | 第三课（支上神）、第四课（辰阴） | 事从内起；入 |

> 「既然四课可以确定内外，我们在分析全课的时候，也要注意**发用与类神是否在四课中出现**，如果出现，要考虑其内外性质，并且要注意**三传与四课上的生克关系**，辨别内外因素的影响程度。」
> 〔通解上 p131｜PDF p146〕

> ⭐ 与第 13 课那条对上了：**发用上克下＝事从外来，下贼上＝事从内起**。两处说的是一件事——一个从"取法方向"看，一个从"位置归属"看。

## 五、宾主：谁去找谁

> 「在预测中要根据**动静法则**，注意区分主客。譬如**我去见人**，以干为我，以支为他，**他为主，我为宾**。如果**他来见我**，他来找我，以干为他，以支为我，此时**他为宾，我为主**。」
> 〔通解上 p132｜PDF p147〕

> ⚠️⚠️ **注意这条会"翻转"**：干支代表谁，取决于**谁主动**。我去求人办事，我是宾；人来求我，我是主。
> 定太极点时**先问一句"这件事是谁发起的"**，否则整盘的利弊会读反。

## 六、尊卑：加临方向定上下

> 「六壬中，**日尊辰卑**，干加支，就是**以尊就卑**。」
> 〔通解上 p132｜PDF p147〕

| 加临关系 | 名目 | 断 |
|---|---|---|
| 干加支，**受支克** | **乱首** | 自取其克 |
| 干加支，**克支** | **残下** | 我克者为财，有**就地取财**之义 |
| 干支**同类** | 帮比 | 培元固本 |
| **下生上** | **偃蹇** | 泄耗虚甚 |
| 干**受支生** | 日俯就 | 初历艰难，终受逸乐 |
| 支加干，**来克干** | **上门乱首** | 为下犯上 |
| 支加干，**来生干** | **自在** | 坐享其成 |
| 干**去生支** | **求受** | 反竭我力而生他 |

〔通解上 p132｜PDF p147〕

> 💡 **一句话记法**：**上下看方向，生克看利弊**。谁加到谁头上是"位置"，加上去之后生还是克才是"结果"。

## 七、地利：内战与外战

同一格上有三层（地盘支、天盘支、天将），它们互相克时，古人分两种：

> 「它们的相克关系有两种，分别为**内战与外战**。**将克神，神克方为外战；方克神，神克将为内战**。」
> 〔通解上 p133｜PDF p148〕

（"将"＝天将，"神"＝天盘支，"方"＝地盘支。）

> 「尤其是**发用、日干等所临的地方，不临空亡，不受克而得生得帮比，就是得地利**。」〔通解上 p133｜PDF p148〕

## 八、⭐ 喜忌二十四字诀

> 「**所有喜忌都主要围绕日干**。所谓喜者有**印、财、禄、德、官、救**等，所谓忌者有**鬼、劫、窃、枭**等。另外还有**马、墓、刑、冲、克、害、合，以及空、陷、旺、相、死、休、囚**，总共二十四个字诀。」
> 〔通解上 p133｜PDF p148〕

| 字 | 原文解 |
|---|---|
| **印** | 能化鬼，能助我 |
| **财** | 能生官，助鬼伤印 |
| **禄** | 旺我，能夺财，仕人喜 |
| **德** | 刚日用禄，柔日用官 |
| **官** | 能合食生印，助枭，常人畏之 |
| **救** | 即子（子孙），能御鬼；无鬼为窃 |
| **鬼** | 病讼皆畏见 |
| **劫比** | 皆夺财克妻 |
| **合** | 畏合煞来伤 |
| **窃** | 宜散，虑成脱 |
| **枭** | 式中只作印看（子平忌之） |
| **马** | 主动：生我恩动，我克财物，克我官动鬼动，同类争财 |
| **墓** | 主静、主暗、主迟、主沉抑、主昏蒙 |
| **刑** | 主不成，衰也伤也；三刑互争，自刑多伤 |
| **冲** | 扰争也，仇雠也，动也 |
| **破** | 废也 |

〔通解上 p133｜PDF p148〕

> ⭐ 这张表的价值在于**它把六亲与神煞统一到"对日干是喜是忌"这一个尺子上**——断课时不必逐个想"这是什么"，只问"对我是帮忙还是添乱"。

## 九、⚠️ 四个坑

1. **宾主不翻转。** 我去求人时我是宾（干为我、支为他）；人来求我时干支代表的人要对调。**先问谁主动**。
2. **把日支一律当"对方"。** 占天雨时支是"所占之地"，占考试时支是"场屋"——**支代表什么由所占之事定**。
3. **只看生克不看加临方向。** 干加支与支加干，同样是克，一个叫残下（就地取财），一个叫上门乱首（下犯上）。
4. **忘了三层之间的内外战。** 天将、天盘支、地盘支互克分内战外战，发用与日干所临之处尤其要看。

## 十、自测

**1.** 我要去见一位领导求办事，起课后干支各代表谁？谁是宾谁是主？

**2.** 占考试，日支代表什么？日支上神受克说明什么？

**3.** 「日克上神」乘吉将与乘凶将，断法差在哪？

**4.** 干加支而被支克，叫什么？支加干而克干呢？

**5.** 什么叫内战、外战？

---

### 答案

**1.** **我去见人**：干为我、支为他；**他为主，我为宾**。（若是他来找我，则反过来：干为他、支为我，我为主、他为宾。）

**2.** 日支代表**场屋**（考场、考试本身），日干才是举子。支上神受克，说明**考试这一头出问题**（场屋不利）——具体还要看谁克它、乘什么将。

**3.** 「日克上神」本身主"事抑塞"，但：**乘吉将则妻利财获**（我克者为财，得财得妻），**乘凶将则财散妻灾**。同一个克，天将定它的性质。

**4.** 干加支受支克叫**乱首**（自取其克）；支加干来克干叫**上门乱首**，为下犯上。

**5.** 三层相克的两种方向：**将克神、神克方为外战**；**方克神、神克将为内战**（将＝天将，神＝天盘支，方＝地盘支）。
