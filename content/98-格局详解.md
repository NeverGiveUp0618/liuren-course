# 大六壬 · 格局详解（中册二十五格）

> **这是什么**：《大六壬通解》**中册整册**是「第五章 六壬格局汇总」，逐格给出成立条件、象曰歌诀、断意、并见变化，还并列了《订讹》《心镜》《观月经》《袖中金》《指窍》《曾门》《定章》等**十几家古籍**的说法。这里把其中**带完整材料的二十五格**整理成可查的条目。
> **和课文的关系**：第 18 课讲九宗门课体的断意，第 19 课讲六十四课经**怎么用**（刻意不做全解，因为逐格判定在 App 的「六十四课经」模块里练）。**本篇是那两课的配套详解**——课上遇到一个格名想知道它到底断什么，翻这里。
> **怎么用**：不必从头读。**起完盘、定完课体，按格名查**；每格开头的「怎么成格」一栏可以反过来当判定条件用。

> ⚠️ **各家说法不一处，两说并列，不替你选**。原书自己就常把《订讹》与《袖中金》的异说并排放着——这是六壬的常态，不是错漏。
> ⚠️ **象曰是断语的骨架，不是全部**。歌诀说"凡占皆凶"的格，遇到年命有救、日用旺相，原书往往紧接着给一条翻盘的条件——那几条才是真正见功夫的地方，本篇一律收在「翻盘的条件」里。

> **出处**：中册书内页 ＝ PDF 页 ＋ 364。下同。

## 1. 游子课

| | |
|---|---|
| **怎么成格** | **三传皆土**（辰戌丑未四季神），且**旬丁**或**天马**发用 |
| **卦体** | 统「观」之体——**云萍聚散**之课 |
| **一句话** | **人待不住了**：住着的想走，走了的想回 |

> 「凡课，**三传皆土**，遇**旬丁、天马**为用，曰游子课。盖土者辰戌丑未，季神归墓……旬丁者，每旬丁干所值之神，主摇动，事最速。天马者，正月起午，顺行六阳位也，又为驿递之神。**身势摇动，使人好游**，故名游子。**居者占之欲游，游者欲还家也**。」
> 〔通解中 p369｜PDF p5〕

**象曰**

> 「丁马加季，奔走西东。**出行吉利，坐守困穷**。疾病难产，官讼多凶。天阴不雨，婚事胡从。」
> 〔通解中 p369｜PDF p5〕

**顺逆之别**——同样三传皆土，方向反过来断意就反：

| 三传走向 | 断 |
|---|---|
| **未→戌→丑**（阴传阳） | 人在家里，**想往外走** |
| **戌→未→辰**（阳传阴） | 人在外头，**想回来** |

**并见别格时**（这一段是游子课最实用的部分）

| 并见 | 断 |
|---|---|
| **斩关** | 为**绝迹**——像范蠡去越、张良归山，**不欲露迹** |
| **淫泆** | 因阴私之事而想远走 |
| **天寇** | 因盗贼之事而想远匿 |
| **行年** | 主**本人想逃** |
| **五墓四杀**＋神将凶 | 事情迍邅，岁内有官灾，破败应在**三年之内** |

**翻盘的条件**

> 「若遇**三奇、六仪**、神将吉，**年命、日辰六处有冲克救神**，可解祸为吉，行人来，出者顺，事多遂意。」
> 〔通解中 p369｜PDF p5〕

**各家补充**

- 《订讹》：见天马又名**海角课**。「**丑加辰为破游，戌加未为衰游，返吟四季为复游**。」〔通解中 p370｜PDF p6〕
- 《心镜》：「三传四季有六丁，不然天马又相并……**若值墓神并杀害，恐有冤家来逼刑**。」〔通解中 p370｜PDF p6〕
- 《指窍》按四季分断：「四季相传丑辰未戌，**春曰稼穑**，而生长以时；**夏曰游子**，而漂流不定；**秋曰地角**，据一隅而亡天下；**冬曰五墓**，舍朝市而守丘墟。」〔通解中 p370｜PDF p6〕

> 💡 《指窍》这条很值得记：**同一个三传皆土，四季占出来是四个名字、四种断法**。这是六壬"同盘异断"的典型——月令不同，象就不同。

## 2. 三交课

| | |
|---|---|
| **怎么成格** | 四仲日占，**四仲加日辰**（一交）＋**三传皆仲**（二交）＋仲神**乘太阴、六合**（三交），三者交加 |
| **卦体** | 统「姤」之体——**风云不测** |
| **一句话** | **事情缠在一起、见不得光** |

> 「四仲者，**子午卯酉四败神**也。四仲日占，遇四仲加支辰阴阳为**一交**；仲神发用，传皆四仲，为**二交**；仲神乘**太阴、六合**将，为**三交**。此三者相遇交加，故名三交。**占者事体勾连**。」
> 〔通解中 p371｜PDF p7〕

**象曰**

> 「**家隐奸私，或自逃匿**。谋事不明，求财无益。讼犯刑名，兵逢战敌。更乘凶将，病患尤极。」
> 〔通解中 p371｜PDF p7〕

**为什么这么凶**——《订讹》讲了根子：

> 「盖**四仲纯全无父子相扶**，是谓四正四平，互刑互破，**前无孟之可隐，后无季之可奔**，如遇兵贼，纵欲逃避而不及矣。」
> 〔通解中 p372｜PDF p8〕

> 💡 对照第 8 课的十杂：四仲（子午卯酉）只有本气、不藏别的东西，所以**无处可躲**——这条断语的物理根据就在那里。

**乘什么将断什么事**

| 乘 | 断 |
|---|---|
| 太阴、六合 | 门户不利，阴小隐匿 |
| 天空 | 虚诈 |
| 玄武 | 遗失 |
| 螣蛇 | 惊怪 |
| 朱雀 | 口舌 |
| 勾陈 | 战斗 |
| 白虎 | 杀伤 |

**阴日阳日之别**

| | 名 | 断 |
|---|---|---|
| **六阳日** | 交罗 | 阴私上门；带凶将恶杀，有杀伤之祸 |
| **六阴日** | 交禄 | 以禄求私；乘玄武为**阴私失禄** |

**几个变体**

| 盘上情形 | 名 | 断 |
|---|---|---|
| 午加酉 | **死交** | 不能成合 |
| 酉加午 | **破交** | 不能成合 |
| 返吟四仲 | **反目交** | 不吉 |
| 无太阴、六合 | **三交不交** | ⚠️ 祸**更甚于**交 |
| 年月日时皆仲 | **三交不解** | ⚠️ 祸**更甚于**交 |

> ⚠️ 「不交」「不解」这两条最容易看漏：**条件差一点反而更凶**，不是"不成格就没事"。原书说得很直：「过与不及，二者祸更甚于交也。」〔通解中 p372｜PDF p8〕

**翻盘的条件**

> 「若**年命日用旺相，乘吉将，传得午卯子**，又名**轩盖**，占官大贵。」
> 〔通解中 p372｜PDF p8〕

> ⚠️ 但轩盖也有反面：《袖中金》说「凡三交见午卯子乘天马、龙、常，即**华盖乘轩**，宜占官。若空亡……则为乘轩落马。」〔通解中 p373｜PDF p9〕——**大贵之象一落空，就变成从车上摔下来**。

## 3. 乱首课

| | |
|---|---|
| **怎么成格** | **日干临支而被支克**（自取乱首）／**支临日干而克干**（上门乱首），发用尤确 |
| **别名** | 白虹贯日；上门乱首发用又名**反常课** |
| **一句话** | **底下的人翻上来了** |

> 「乱首：**干临支被克，为自取乱首。支临干克干，为上门乱首**，更兼发用尤的。下为尊上如首，支为卑下如足，**卑下无礼作乱**，故名乱首。上门乱首发用，又名反常课。」
> 〔通解中 p376｜PDF p12〕

> 〔存疑〕「**下**为尊上如首」一句，与下半句「支为卑下如足」对不上——按上下文当作「**日**为尊上如首」（日干为尊、日支为卑），"下""日"形近易讹。**原书字面如此，照录不改**。

**歌诀两首**

> 「日为尊者父，辰作少年儿。尊者来加子，少者反克之。**因名为乱首，老者必低蕤**。家内应无礼，官司忌有仪。**先祖是外姓，上宗别人儿**。纵必家和顺，官司亦被欺。」
> 〔通解中 p375｜PDF p11〕

> 「日往加辰辰克日，发用当为乱首名。**臣叛君兮子杀父，妻背夫兮弟克兄。奴婢不从主委任，将军出塞偾其兵**。日为尊长辰卑小，犯上之时忌此刑。」
> 〔通解中 p375｜PDF p11〕

**两种乱首，事体轻重不同**

| | 怎么成 | 事体 | 兵家 |
|---|---|---|---|
| **自取乱首** | 干临支被克 | **较轻**——尊上自己失了礼，才被下面犯 | 事发于内起于外；**不利客**，宜固守解围 |
| **上门乱首** | 支临干克干 | **重**——尊上没惹他，卑下敢来犯上 | 事发于外起于内；**不利主**，来人多迟、营寨多刑伤 |

**⭐ 一条很特别的断法**

> 「凡乱首课皆主**杂乱之姓**，上祖必假名异姓。」「此课或主**祖宗别姓**。」
> 〔通解中 p375-376｜PDF p11-12〕

> 💡 这是六壬断"家世"的少数几条硬规则之一——乱首课出来，可以问对方**上祖是不是改过姓、过继过、或家里有别姓同住**。对得上，后面的话就好说了。

**并见**：若见**卯酉**、乘**天后六合**，主男女讹杂、不分长幼。自取乱首若四课俱下贼上，「不免窝犯丑声，祸自内出」。

**翻盘的条件**：三传或年命上有克制"乱我之神"者，名**患门救**。〔通解中 p376｜PDF p12〕

**附：干临支的另外三种情形**（不成乱首，一并记着）

| 干临支而…… | 名 | 断 |
|---|---|---|
| **生支** | 偃蹇 | 泄耗太过 |
| **受支生** | 俯就 | 先难后乐 |
| **与支同类** | 培本 | 比和相助 |

**凌犯格**（乱首的近亲，别混）

> 「日克辰，乃上凌下，却得**下贼上为用**；辰克日，乃下犯上，却得**上克下为用**。互相凌犯，故名凌犯。」
> 〔通解中 p376｜PDF p12〕

断：尊卑不分，君骄臣逆，或主篡弑之事。**初传是官鬼则祸尤速**。

## 4. 赘婿课

| | |
|---|---|
| **怎么成格** | **日干克支，且干支互临发用**——干临支（男就女）或支临干（女就男） |
| **卦体** | 统「旅」之体——**为客求财**之课 |
| **一句话** | **寄人篱下，身不由己** |

> 「凡课，日干克辰，又自加临为用，曰赞婿课。盖**干为夫，支为妻**，干克者为妻财。**干临支以动就静**，如男子婿赞妻家。**支临干以静就动**，如妇人随男就嫁，此舍己从人，以身入赘，为赞婿。**占者凡事不快，寓居于人，身不自由**。」
> 〔通解中 p377｜PDF p13〕

《订讹》讲得更白，还给了两个俗名：

> 「赘婿：干为夫，支为妇，干临支以动就静，如男子身赘妻家，**俗所谓坐堂婿**。支临干，以静就动，如妇人携男就嫁，**俗所谓随娘儿**。皆舍己从人，以身入赘，故名赘婿。」
> 〔通解中 p378｜PDF p14〕

> 〔存疑〕正文一处写作「**赞**婿课」「男子婿**赞**妻家」，《订讹》处写作「**赘**婿」——**"赞"当是"赘"之讹**（形近），全书通行的名字是赘婿。两处字面都照录。

**象曰**

> 「**屈意从人，事多牵制**。胎孕迟延，行人淹滞。**财名可成**，病讼未济。兵利为客，先动胜计。」
> 〔通解中 p378｜PDF p14〕

> 💡 注意象曰里夹着一句**「财名可成」**——赘婿虽是憋屈之课，**求财求名反而办得成**，只是要看人脸色。这就是它被归在「为客求财」的缘故。

**两种方向**

| | 断 | 兵家 |
|---|---|---|
| **日往加辰**（干克支） | 男就女，**利尊长不利卑幼**，宜动不宜静 | 利为客，见阵**先动者胜** |
| **辰来加日**（支克干） | 女就男，**卑凌尊而尊长不容** | 客反为主，宜他来干我、我能胜之 |

**乘将**：白虎主杀伤，勾陈主斗讼，朱雀口舌，螣蛇惊恐；遇**天后**主恩泽，**天乙**主官长，**六合**主阴私（更主招婿婚姻），**太常**主酒食。

**旺衰定成败**

| 日用 | 断 |
|---|---|
| **休囚**乘凶将 | 病人**传染不脱**（旅九三「丧其童仆，贞厉」） |
| **旺相**乘吉将 | 凡事谋为可就（旅六二「得童仆，贞」） |

**⭐ 十个日子的具体断语**（《订讹》，可直接照用）

> 「甲戌日戊临甲，有女子衣服事；甲辰日辰临甲，有斗讼事；乙未日未临乙，有酒食言语事；癸巳日巳临癸，有争衣服惊恐事；己亥日亥临己，有女子惊逃事；丁酉日酉临丁，有分离事；壬午日午临壬，有田宅相连事；戊子日子临戊，有女子疾病、就人财物事；丙申日申临丙，有言他人事；辛卯日卯临辛，有木器伤财事。」
> 〔通解中 p379｜PDF p15〕

**两个变体**

| 情形 | 名 | 断 |
|---|---|---|
| 干临支克支，**乘囚死作六合、太阴** | 正赘婿 | 如上 |
| 干临支克支，**乘旺相作勾陈、白虎** | **残下** | ⚠️ **甚不利卑小** |
| 中传见救神克日，或年命神将吉 | **赘婿当权** | **可任意所为**——反客为主 |

**附：支临干的另外三种情形**

| 支临干而…… | 名 | 断 |
|---|---|---|
| **生干** | 自在 | 坐享 |
| **受干生** | 求受 | 反竭我力 |
| **与干同类** | 壮基 | 并国相济 |

> ⚠️ 若**支上乘脱气**，原书说「必无正屋可居，终非自立之象」——占住处、占能不能自立时，这条比象曰更管用。

## 5. 冲破课

| | |
|---|---|
| **怎么成格** | **日辰的冲神、加在破位上发用**；或用神与岁月日时相冲破 |
| **卦体** | 统「夬」之体——**雪上加霜** |
| **一句话** | **先动摇，再散架** |

> 「凡课，日辰之冲神，加破为用，曰冲破课。**冲者，动摇也。初虽有德，后必倾覆**。」
> 「**破者，解散也**，主事更改，多有中辍……盖**冲主反复，破主倾坏**，冲破凶为一类，故名冲破。」
> 〔通解中 p381｜PDF p17〕

**象曰**

> 「人情反复，门户不宁。婚姻不遂，胎孕难成。疾病凶散，财利事平。**凡有谋望，成而复倾**。」
> 〔通解中 p381｜PDF p17〕

**六冲各主什么**（这张表单独拿出来也好用）

| 冲 | 断 |
|---|---|
| **子午** | 道路驰逐，男女争谋变动 |
| **卯酉** | 门户改移，或逃亡失脱，外人淫乱奸私 |
| **寅申** | 人鬼相伤，**夫妇异心** |
| **巳亥** | 事反复无实，**重求轻得** |
| **丑未** | 兄弟兴衰相持，谋心不同，干事不遂 |
| **辰戌** | 主仆离异，贵贱不明，不义之争 |

**破各主什么**

| 破 | 断 |
|---|---|
| 午破卯、酉破子 | 门户破败，阴小有灾 |
| 辰破丑 | 丘墓寺观破损 |
| 戌破未 | **先破后刑** |
| 亥破寅、申破巳 | **先破后合** |

**⭐ 冲不是一味的坏——四句口诀**

> 「此课**旺不宜冲，衰墓宜冲；吉不宜冲，凶将宜冲；凶空不宜冲，吉凶宜冲**。类神空亡，岁月冲则**暗动**，日辰次之。**破不宜望成事，宜散凶事**。」
> 〔通解中 p382｜PDF p18〕

> 〔存疑〕《订讹》末一句作「**吉凶宜冲**」，与它前半句「凶空不宜冲」对不上——正文另一处说的是「**吉空宜冲，凶空不宜冲**」〔通解中 p381｜PDF p17〕，按那处理解才通顺。**两处字面都照录，不替它改**。

| 什么状态 | 该不该冲 |
|---|---|
| 旺相 | **不宜**冲（冲动则为凶） |
| 衰、墓 | **宜**冲（冲开才活） |
| 吉神吉将 | **不宜**冲 |
| 凶将、死神丧车恶杀 | **宜**冲（冲散则不成争） |
| **吉神落空** | **宜**冲（冲则反实） |
| **凶神落空** | **不宜**冲（冲实了反而成真） |

> 💡 「**冲则反实**」是六壬很要紧的一条：空亡的字被冲，反而变成实的。所以**吉空要冲、凶空怕冲**——这条和第 7 课的旬空、第 16 课的应期都接得上。

## 6. 淫泆课

| | |
|---|---|
| **怎么成格** | **初传卯或酉**发用，且乘**天后**或**六合** |
| **卦体** | 统「既济」之体——阴阳配合 |
| **一句话** | **私情**：利私谋，不利公谋 |

> 「盖**卯、酉为阴私之门，后、合乃淫欲之神**，主淫奔泆欲，故名淫泆课……凡系淫泆课，**利私谋而不利公谋**也。」
> 〔通解中 p384｜PDF p20〕

**象曰**

> 「男子就室，女妇有家。阴私莫禁，淫欲转加。嫁娶不吉，逃亡可嘉。**捕捉难获，访人自差**。」
> 〔通解中 p384｜PDF p20〕

**⭐ 两个格，方向正好相反**（这一对最实用：能断是男追女还是女追男）

| 三传 | 名 | 断 |
|---|---|---|
| **用起六合 → 终于天后** | **狡童格** | **男诱女**，有逃亡之事——"如狡顽好色之童，不顾廉耻之风" |
| **用起天后 → 终于六合** | **泆女格** | **女随男**，有通私奔走之事——"如淫奔泆欲、自嫁之女" |

《心镜》把这一对压成两句：

> 「欲知男女为淫荡，更向传中把将论。**六合即知男诱妇，天后女携男子奔**。」
> 〔通解中 p385｜PDF p21〕

**并见**

| 并见 | 断 |
|---|---|
| **三交** | 浊滥淫泆——**所私非一人一处** |
| **天罗、地网** | 甚凶，又主恶声 |
| 并**天烦** | 男遭杀伤 |
| 并**地烦** | 女遭杀伤 |
| 并**二烦、九丑** | **男女皆遭杀伤** |

**⭐ 占婚时的两条现成断语**

- 「若**后、合临日辰、男女行年**并者，占婚**不用媒，先奸后娶**。」
- 「**值空亡为虚意**也。」
> 〔通解中 p384｜PDF p20〕

> ⚠️ **上克下与下贼上，过错在谁不一样**：《定章》说「**上克下，过在男子；下贼上，过在女人**」；乘生合是"蔽翳"（两情相悦），乘相克是"强逼"。〔通解中 p386｜PDF p22〕这条决定了同一个淫泆课能断成两回事，别漏。

## 7. 芜淫课

| | |
|---|---|
| **怎么成格** | **四课有克但缺一课**（不备），或**日辰交互相克** |
| **卦体** | 统「小畜」之体——**琴瑟不调** |
| **一句话** | **夫妻各有各的心思** |

> 「凡见**二阳一阴为阴不备**，如二男争一女。**二阴一阳为阳不备**，若二女争一男。及日辰交互相克，各自相生是也。此**夫妻皆有私通，两情相背，荒淫无度**，故名芜淫。」
> 〔通解中 p386｜PDF p22〕

**象曰**

> 「阴阳不备，交克最嫌。利名碌碌，狱病淹淹。阴微晴久，阳少雨添。行人未至，征战愁占。」
> 〔通解中 p386｜PDF p22〕

**⚠️ 怎么数"缺一课"——最容易错的一步**

> 「课得不备，**刚日从日上起第一课，柔日从辰上起第一课**。」
> 〔通解中 p386｜PDF p22〕

《订讹》把道理讲透了：第一课是干阳、第二课是干阴、第三课是支阳、第四课是支阴——

> 「盖第一课为干阳，第二课为干阴，第三课为支阳，第四课为支阴。**阴课缺一为阴不周全，阳课缺一为阳不周全。以四课之阴阳论，非以干支之阴阳论也**。」
> 〔通解中 p388｜PDF p24〕

> 💡 关键在于**一个上神只能占一个位子**。乙卯日午时未将，巳辰既然已经当了支的阴神（第二课），就**不能再拿去当干的阳神**（第三课）——于是四课只剩三课，这才叫"不备"。数错的人多半是把同一个上神数了两遍。

**阴不备与阳不备，断法相反**

| | 怎么成 | 断 | 兵家 |
|---|---|---|---|
| **阳不备** | 二阴一阳 | **二女争一男** | 利为主，**贼不来** |
| **阴不备** | 二阳一阴 | **二男争一女** | 利为客，**贼必来**，但战不成 |

**通用断**

> 「占主不周全，物偏缺，病难愈，求望难成，行人未至……**三传阳多，事起男；三传阴多，事因女**。阳多晴久，阴多雨添。凡占多以不周全为断。」
> 〔通解中 p388｜PDF p24〕

**翻盘的条件**

> 「或**四课备、神将吉兼有救神**，及**课不备、无克不凶**，事有迟延，**夫妻拆散终复团圆**。」
> 〔通解中 p386｜PDF p22〕

> ⚠️ **「芜淫」是象，不是判词**。中册自己的案例里就为这个吵过一轮——占雇工得芜淫，断的是"两主争一仆"而不是男女私情。原书按语说得很直：

> 「凡课须识得一象字，如《毕法》云：『夫妻芜淫各有私』，**此象也，非死局也**。须看所占何事。**如占家宅夫妇可断芜淫，若宾主往来交际，亦曰两男争一女乎？**」
> 〔通解中 p377｜PDF p13〕

## 8. 解离课

| | |
|---|---|
| **怎么成格** | **夫妻行年上下互相冲克**；或干支上神互相克贼 |
| **一句话** | **各有各的心** |

> 「凡**夫妻行年冲克**，及上下神互相克贼，为解离格……上下互相克贼，**天地解离，各有异心**，故名解离。**占者非断弦之凶，必有反目之兆也**。」
> 〔通解中 p389｜PDF p25〕

**⭐ 和芜淫课怎么分**（这是两格最容易混的地方，原书专门交代过）

> 「**芜淫与解离之所以分者，芜淫乃干支上神互克下，解离乃干支互克上神**。至于年命互克，则同取。」
> 〔通解中 p391｜PDF p27〕

| | 克的是什么 |
|---|---|
| **芜淫** | 干支的**上神去克下** |
| **解离** | 干支**互克对方的上神** |
| 年命互相克 | **两格都算** |

**《毕法》给的判定**

> 「**真解离卦者，谓干克支上神，支克干上神**。或夫妇行年又值此者尤的。此时占人必占解离事。」
> 〔通解中 p391｜PDF p27〕

**歌诀**

> 「夫妻天匹配，有难解离频。**年命交相克**，始终亦同陈……**递相淫情起，暗地使媒人**。」
> 〔通解中 p390｜PDF p26〕

> ⚠️ 注解里点明了要害：「**此不与四课三全之事同，若两家行年相克，夫有外妻，妻有外夫心**。」〔通解中 p390｜PDF p26〕——解离**不看四课三传，只看两人的行年**。所以占婚必须先问双方年岁，不然这一格根本用不上。

**《曾门》的始终之说**

> 「夫以阳年为始，阴年为终。妻以阴年为始，阳年为终。**终始相生，为和合。终始相克，为俱解**。」
> 〔通解中 p391｜PDF p27〕

## 9. 孤寡课

| | |
|---|---|
| **怎么成格** | **地盘空亡为孤辰，天盘空亡为寡宿**；或按四时取（见下表）发用 |
| **一句话** | **前去后空，孤身一个** |

> 「**地盘空亡为孤辰，天盘空亡为寡宿**。盖十干不到之地，五行脱空之乡，**能减凶祸，主人孤独离乡背井也**。」
> 〔通解中 p392｜PDF p28〕

**四时孤寡表**（各看发用）

| 季 | 孤辰 | 寡宿 |
|---|---|---|
| 春 | 巳午 | 子丑 |
| 夏 | 申酉 | 卯辰 |
| 秋 | 亥子 | 午未 |
| 冬 | 寅卯 | 酉戌 |

**断**

> 「占主孤独，离乡背井，官易位，财空手，婚断弦，孕虚有，出入防盗。**日辰无气最凶**。**孤辰，父母灾**，亦主离宗弃祖。**寡宿，妻子离**，六亲叛。如**旬孤寡又并四时孤寡，为空孤空寡，更凶**。」
> 〔通解中 p393｜PDF p29〕

**⭐ 空亡的几条实战规矩**（这一段其实是第 7 课旬空的加强版，很值得单独记）

> 「凡值空亡，忧喜皆不成，托人多诈。谋望**近事，出旬可图；远事终难**。时空事亦难成。
> 或**中传空为断桥折腰**，主事中止难就。或**中末俱空，为移远就近**，动中不动，寻远人即在近也。
> **初中空推末传，中末空取初传**，以不空者断吉凶。
> **新病空病，久病空人。吉空反凶，凶空反吉**。」
> 〔通解中 p393｜PDF p29〕

| 空在哪 | 断 |
|---|---|
| **中传空** | **断桥折腰**——事到半路中止 |
| **中末俱空** | **移远就近**——动中不动，找远人其实就在近处 |
| 初中空 | 推末传 |
| 中末空 | 取初传 |

> 💡 「**新病空病，久病空人**」是占病的一条硬口诀：新病遇空，空掉的是病（好得快）；**久病遇空，空掉的是人**。

**翻盘的条件**

> 「或遇**三奇六仪**为救神，及遇**太岁、月将、月建**，为**孤寡再醮**。又今日所坐位值孤寡为用，曰**孤寡得位**（如庚日用申是也）。皆主**反祸为福，事前破后成**。」
> 〔通解中 p393｜PDF p29〕

## 10. 度厄课

| | |
|---|---|
| **怎么成格** | 四课内**三上克下**（幼度厄）或**三下贼上**（长度厄） |
| **卦体** | 统「剥」之体——**六亲冰炭** |
| **一句话** | **家里有人要遭殃，看是老的还是小的** |

> 「盖上为尊，下为卑。**三上克下，则长欺幼**，势必遭厄，为度厄。**三下贼上，则长不正，幼乃凌长**，为度厄。占者**家宅欠利，老幼见灾**。」
> 〔通解中 p394｜PDF p30〕

**象曰**

> 「事忧老幼，患病重来。家门不吉，骨肉尤乖。出军失利，行者多灾。**类神旺相，祸去福来**。」
> 〔通解中 p395｜PDF p31〕

**两种度厄，遭殃的人不同**

| | 怎么成 | 谁遭殃 |
|---|---|---|
| **幼度厄** | 三上克下 | **卑小**——子孙发用又逢凶神入墓，卑者更凶 |
| **长度厄** | 三下贼上 | **尊上**——父母发用又逢凶神入墓，尊者更凶 |

**发用是阳神还是阴神，应在谁身上**

> 「如**发用阳神乘凶将，主伯叔尊长有灾。阴神主姑姨幼小有灾**。」
> 〔通解中 p395｜PDF p31〕

**翻盘的条件**：「日用旺相乘吉将，**主幼得长力，长得幼力**。」〔通解中 p395｜PDF p31〕
《订讹》另给一条：「此二课……**俱不吉，然有救又不以凶断**。如火克金则水为救之类。」〔通解中 p395｜PDF p31〕

## 11. 无禄课 / 绝嗣课

| | |
|---|---|
| **怎么成格** | **四上俱克下**＝无禄；**四下俱贼上**＝绝嗣 |
| **卦体** | 统「否」之体——**上下僭乱** |
| **一句话** | **上下彻底翻脸**，比度厄更绝 |

> 「凡课**四上俱克下，为无禄课**。盖日神阴阳俱相克，不得其所，不免投辰上两课，辰上阴阳又相克，**则无所投之路**，占者多主孤独。」
> 〔通解中 p397｜PDF p33〕

**象曰**

> 「**上克无禄，下克绝嗣**。君臣悖逆，父子分离。求谋不遂，动作多疑。**三传有救，方免灾危**。」
> 〔通解中 p397｜PDF p33〕

**两格对照**（断法几乎处处相反，别记混）

| | **无禄**（四上克下） | **绝嗣**（四下贼上） |
|---|---|---|
| 义 | 上不容下，为**不恕** | 下不敬上，为**不忠** |
| 断 | 庶人不禄；**有官罚职**，轻则罚俸，重则削职 | 小人无礼、暗算、横灾殃祸 |
| 病 | 病必死 | 病者易死 |
| 事起于 | **女人** | **男子** |
| 兵讼 | **后者胜**（宜后对） | **先者胜**（宜先起） |
| 动静 | **静而必动** | **动而必静** |
| 六亲 | 孤独失业，多刑伤 | 尊长见灾，奴婢逃，骨肉散 |

> ⚠️ 《订讹》与正文在"兵讼谁胜"上给的是**相反的说法**——正文说无禄「对敌利客，讼宜先起者胜」〔通解中 p397｜PDF p33〕，《订讹》说无禄「兵讼后者胜」〔通解中 p398｜PDF p34〕。**两说并列，不替你选**；实占时以年命、救神的向背为准。

**⭐ 救神怎么找**（这一格的救最要紧，《观月经》注解讲得最细）

> 「四课俱临下者，为无禄卦。**如发用是水神，末传得金神为救。发用是金神，三传见土神为救神**……虽是无禄卦，不言绝也。」
> 〔通解中 p398｜PDF p34〕

**救神＝生发用的那一行**（金生水、土生金）。三传里能接上这一环，凶格就不作绝断。

> 💡 绝嗣课的救法同理：己未日四下贼上、三传巳戌卯，「初巳火发用，与今日己土比合，中传戌土为子孙，末传卯木为父母，**不得言绝嗣，为有救也**」。〔通解中 p399｜PDF p35〕
