# 大六壬 · 格局详解（中册二十五格）

> **这是什么**：《大六壬通解》**中册整册**是「第五章 六壬格局汇总」，逐格给出成立条件、象曰歌诀、断意、并见变化，还并列了《订讹》《心镜》《观月经》《袖中金》《指窍》《曾门》《定章》等**十几家古籍**的说法。这里把其中**带完整材料的二十五格**整理成可查的条目。
> **和课文的关系**：第 18 课讲九宗门课体的断意，第 19 课讲六十四课经**怎么用**（刻意不做全解，因为逐格判定在 App 的「六十四课经」模块里练）。**本篇是那两课的配套详解**——课上遇到一个格名想知道它到底断什么，翻这里。
> **怎么用**：不必从头读。**起完盘、定完课体，按格名查**；每格开头的「怎么成格」一栏可以反过来当判定条件用。

> ⚠️ **各家说法不一处，两说并列，不替你选**。原书自己就常把《订讹》与《袖中金》的异说并排放着——这是六壬的常态，不是错漏。
> ⚠️ **象曰是断语的骨架，不是全部**。歌诀说"凡占皆凶"的格，遇到年命有救、日用旺相，原书往往紧接着给一条翻盘的条件——那几条才是真正见功夫的地方，本篇一律收在「翻盘的条件」里。

> **出处**：中册书内页 ＝ PDF 页 ＋ 364。下同。

## 1. 游子课

| | |
|---|---|
| **怎么成格** | **三传皆土**（辰戌丑未四季神），且**旬丁**或**天马**发用 |
| **卦体** | 统「观」之体——**云萍聚散**之课 |
| **一句话** | **人待不住了**：住着的想走，走了的想回 |

> 「凡课，**三传皆土**，遇**旬丁、天马**为用，曰游子课。盖土者辰戌丑未，季神归墓……旬丁者，每旬丁干所值之神，主摇动，事最速。天马者，正月起午，顺行六阳位也，又为驿递之神。**身势摇动，使人好游**，故名游子。**居者占之欲游，游者欲还家也**。」
> 〔通解中 p369｜PDF p5〕

**象曰**

> 「丁马加季，奔走西东。**出行吉利，坐守困穷**。疾病难产，官讼多凶。天阴不雨，婚事胡从。」
> 〔通解中 p369｜PDF p5〕

**顺逆之别**——同样三传皆土，方向反过来断意就反：

| 三传走向 | 断 |
|---|---|
| **未→戌→丑**（阴传阳） | 人在家里，**想往外走** |
| **戌→未→辰**（阳传阴） | 人在外头，**想回来** |

**并见别格时**（这一段是游子课最实用的部分）

| 并见 | 断 |
|---|---|
| **斩关** | 为**绝迹**——像范蠡去越、张良归山，**不欲露迹** |
| **淫泆** | 因阴私之事而想远走 |
| **天寇** | 因盗贼之事而想远匿 |
| **行年** | 主**本人想逃** |
| **五墓四杀**＋神将凶 | 事情迍邅，岁内有官灾，破败应在**三年之内** |

**翻盘的条件**

> 「若遇**三奇、六仪**、神将吉，**年命、日辰六处有冲克救神**，可解祸为吉，行人来，出者顺，事多遂意。」
> 〔通解中 p369｜PDF p5〕

**各家补充**

- 《订讹》：见天马又名**海角课**。「**丑加辰为破游，戌加未为衰游，返吟四季为复游**。」〔通解中 p370｜PDF p6〕
- 《心镜》：「三传四季有六丁，不然天马又相并……**若值墓神并杀害，恐有冤家来逼刑**。」〔通解中 p370｜PDF p6〕
- 《指窍》按四季分断：「四季相传丑辰未戌，**春曰稼穑**，而生长以时；**夏曰游子**，而漂流不定；**秋曰地角**，据一隅而亡天下；**冬曰五墓**，舍朝市而守丘墟。」〔通解中 p370｜PDF p6〕

> 💡 《指窍》这条很值得记：**同一个三传皆土，四季占出来是四个名字、四种断法**。这是六壬"同盘异断"的典型——月令不同，象就不同。

**讲义（六十四课经）**

> 「游子季用又乘丁，再遇天马走西东。」
> 〔讲义·课目总歌〕

| | |
|---|---|
| **怎么成格（讲义）** | 凡课，三传皆土，遇旬丁、天马为用，曰游子课。 |
| **归类** | 动阻隐伏 |

〔出处〕讲义中册·第五章

## 2. 三交课

| | |
|---|---|
| **怎么成格** | 四仲日占，**四仲加日辰**（一交）＋**三传皆仲**（二交）＋仲神**乘太阴、六合**（三交），三者交加 |
| **卦体** | 统「姤」之体——**风云不测** |
| **一句话** | **事情缠在一起、见不得光** |

> 「四仲者，**子午卯酉四败神**也。四仲日占，遇四仲加支辰阴阳为**一交**；仲神发用，传皆四仲，为**二交**；仲神乘**太阴、六合**将，为**三交**。此三者相遇交加，故名三交。**占者事体勾连**。」
> 〔通解中 p371｜PDF p7〕

**象曰**

> 「**家隐奸私，或自逃匿**。谋事不明，求财无益。讼犯刑名，兵逢战敌。更乘凶将，病患尤极。」
> 〔通解中 p371｜PDF p7〕

**为什么这么凶**——《订讹》讲了根子：

> 「盖**四仲纯全无父子相扶**，是谓四正四平，互刑互破，**前无孟之可隐，后无季之可奔**，如遇兵贼，纵欲逃避而不及矣。」
> 〔通解中 p372｜PDF p8〕

> 💡 对照第 8 课的十杂：四仲（子午卯酉）只有本气、不藏别的东西，所以**无处可躲**——这条断语的物理根据就在那里。

**乘什么将断什么事**

| 乘 | 断 |
|---|---|
| 太阴、六合 | 门户不利，阴小隐匿 |
| 天空 | 虚诈 |
| 玄武 | 遗失 |
| 螣蛇 | 惊怪 |
| 朱雀 | 口舌 |
| 勾陈 | 战斗 |
| 白虎 | 杀伤 |

**阴日阳日之别**

| | 名 | 断 |
|---|---|---|
| **六阳日** | 交罗 | 阴私上门；带凶将恶杀，有杀伤之祸 |
| **六阴日** | 交禄 | 以禄求私；乘玄武为**阴私失禄** |

**几个变体**

| 盘上情形 | 名 | 断 |
|---|---|---|
| 午加酉 | **死交** | 不能成合 |
| 酉加午 | **破交** | 不能成合 |
| 返吟四仲 | **反目交** | 不吉 |
| 无太阴、六合 | **三交不交** | ⚠️ 祸**更甚于**交 |
| 年月日时皆仲 | **三交不解** | ⚠️ 祸**更甚于**交 |

> ⚠️ 「不交」「不解」这两条最容易看漏：**条件差一点反而更凶**，不是"不成格就没事"。原书说得很直：「过与不及，二者祸更甚于交也。」〔通解中 p372｜PDF p8〕

**翻盘的条件**

> 「若**年命日用旺相，乘吉将，传得午卯子**，又名**轩盖**，占官大贵。」
> 〔通解中 p372｜PDF p8〕

> ⚠️ 但轩盖也有反面：《袖中金》说「凡三交见午卯子乘天马、龙、常，即**华盖乘轩**，宜占官。若空亡……则为乘轩落马。」〔通解中 p373｜PDF p9〕——**大贵之象一落空，就变成从车上摔下来**。

**讲义（六十四课经）**

> 「三交四仲来加仲，三传皆仲阴合逢。」
> 〔讲义·课目总歌〕

| | |
|---|---|
| **怎么成格（讲义）** | 凡四仲日占，四仲加日辰，三传皆仲将，逢阴合，为三交课。 |
| **归类** | 动阻隐伏 |

〔出处〕讲义中册·第五章

## 3. 乱首课

| | |
|---|---|
| **怎么成格** | **日干临支而被支克**（自取乱首）／**支临日干而克干**（上门乱首），发用尤确 |
| **别名** | 白虹贯日；上门乱首发用又名**反常课** |
| **一句话** | **底下的人翻上来了** |

> 「乱首：**干临支被克，为自取乱首。支临干克干，为上门乱首**，更兼发用尤的。下为尊上如首，支为卑下如足，**卑下无礼作乱**，故名乱首。上门乱首发用，又名反常课。」
> 〔通解中 p376｜PDF p12〕

> 〔存疑〕「**下**为尊上如首」一句，与下半句「支为卑下如足」对不上——按上下文当作「**日**为尊上如首」（日干为尊、日支为卑），"下""日"形近易讹。**原书字面如此，照录不改**。

**歌诀两首**

> 「日为尊者父，辰作少年儿。尊者来加子，少者反克之。**因名为乱首，老者必低蕤**。家内应无礼，官司忌有仪。**先祖是外姓，上宗别人儿**。纵必家和顺，官司亦被欺。」
> 〔通解中 p375｜PDF p11〕

> 「日往加辰辰克日，发用当为乱首名。**臣叛君兮子杀父，妻背夫兮弟克兄。奴婢不从主委任，将军出塞偾其兵**。日为尊长辰卑小，犯上之时忌此刑。」
> 〔通解中 p375｜PDF p11〕

**两种乱首，事体轻重不同**

| | 怎么成 | 事体 | 兵家 |
|---|---|---|---|
| **自取乱首** | 干临支被克 | **较轻**——尊上自己失了礼，才被下面犯 | 事发于内起于外；**不利客**，宜固守解围 |
| **上门乱首** | 支临干克干 | **重**——尊上没惹他，卑下敢来犯上 | 事发于外起于内；**不利主**，来人多迟、营寨多刑伤 |

**⭐ 一条很特别的断法**

> 「凡乱首课皆主**杂乱之姓**，上祖必假名异姓。」「此课或主**祖宗别姓**。」
> 〔通解中 p375-376｜PDF p11-12〕

> 💡 这是六壬断"家世"的少数几条硬规则之一——乱首课出来，可以问对方**上祖是不是改过姓、过继过、或家里有别姓同住**。对得上，后面的话就好说了。

**并见**：若见**卯酉**、乘**天后六合**，主男女讹杂、不分长幼。自取乱首若四课俱下贼上，「不免窝犯丑声，祸自内出」。

**翻盘的条件**：三传或年命上有克制"乱我之神"者，名**患门救**。〔通解中 p376｜PDF p12〕

**附：干临支的另外三种情形**（不成乱首，一并记着）

| 干临支而…… | 名 | 断 |
|---|---|---|
| **生支** | 偃蹇 | 泄耗太过 |
| **受支生** | 俯就 | 先难后乐 |
| **与支同类** | 培本 | 比和相助 |

**凌犯格**（乱首的近亲，别混）

> 「日克辰，乃上凌下，却得**下贼上为用**；辰克日，乃下犯上，却得**上克下为用**。互相凌犯，故名凌犯。」
> 〔通解中 p376｜PDF p12〕

断：尊卑不分，君骄臣逆，或主篡弑之事。**初传是官鬼则祸尤速**。

**讲义（六十四课经）**

> 「乱首支加干克干，干加支上被克同。」
> 〔讲义·课目总歌〕

| | |
|---|---|
| **怎么成格（讲义）** | 干临支被克，为自取乱首；支临干克干，为上门乱首，更兼发用尤的。 |
| **归类** | 动阻隐伏 |

〔出处〕讲义中册·第五章

## 4. 赘婿课

| | |
|---|---|
| **怎么成格** | **日干克支，且干支互临发用**——干临支（男就女）或支临干（女就男） |
| **卦体** | 统「旅」之体——**为客求财**之课 |
| **一句话** | **寄人篱下，身不由己** |

> 「凡课，日干克辰，又自加临为用，曰赞婿课。盖**干为夫，支为妻**，干克者为妻财。**干临支以动就静**，如男子婿赞妻家。**支临干以静就动**，如妇人随男就嫁，此舍己从人，以身入赘，为赞婿。**占者凡事不快，寓居于人，身不自由**。」
> 〔通解中 p377｜PDF p13〕

《订讹》讲得更白，还给了两个俗名：

> 「赘婿：干为夫，支为妇，干临支以动就静，如男子身赘妻家，**俗所谓坐堂婿**。支临干，以静就动，如妇人携男就嫁，**俗所谓随娘儿**。皆舍己从人，以身入赘，故名赘婿。」
> 〔通解中 p378｜PDF p14〕

> 〔存疑〕正文一处写作「**赞**婿课」「男子婿**赞**妻家」，《订讹》处写作「**赘**婿」——**"赞"当是"赘"之讹**（形近），全书通行的名字是赘婿。两处字面都照录。

**象曰**

> 「**屈意从人，事多牵制**。胎孕迟延，行人淹滞。**财名可成**，病讼未济。兵利为客，先动胜计。」
> 〔通解中 p378｜PDF p14〕

> 💡 注意象曰里夹着一句**「财名可成」**——赘婿虽是憋屈之课，**求财求名反而办得成**，只是要看人脸色。这就是它被归在「为客求财」的缘故。

**两种方向**

| | 断 | 兵家 |
|---|---|---|
| **日往加辰**（干克支） | 男就女，**利尊长不利卑幼**，宜动不宜静 | 利为客，见阵**先动者胜** |
| **辰来加日**（支克干） | 女就男，**卑凌尊而尊长不容** | 客反为主，宜他来干我、我能胜之 |

**乘将**：白虎主杀伤，勾陈主斗讼，朱雀口舌，螣蛇惊恐；遇**天后**主恩泽，**天乙**主官长，**六合**主阴私（更主招婿婚姻），**太常**主酒食。

**旺衰定成败**

| 日用 | 断 |
|---|---|
| **休囚**乘凶将 | 病人**传染不脱**（旅九三「丧其童仆，贞厉」） |
| **旺相**乘吉将 | 凡事谋为可就（旅六二「得童仆，贞」） |

**⭐ 十个日子的具体断语**（《订讹》，可直接照用）

> 「甲戌日戊临甲，有女子衣服事；甲辰日辰临甲，有斗讼事；乙未日未临乙，有酒食言语事；癸巳日巳临癸，有争衣服惊恐事；己亥日亥临己，有女子惊逃事；丁酉日酉临丁，有分离事；壬午日午临壬，有田宅相连事；戊子日子临戊，有女子疾病、就人财物事；丙申日申临丙，有言他人事；辛卯日卯临辛，有木器伤财事。」
> 〔通解中 p379｜PDF p15〕

**两个变体**

| 情形 | 名 | 断 |
|---|---|---|
| 干临支克支，**乘囚死作六合、太阴** | 正赘婿 | 如上 |
| 干临支克支，**乘旺相作勾陈、白虎** | **残下** | ⚠️ **甚不利卑小** |
| 中传见救神克日，或年命神将吉 | **赘婿当权** | **可任意所为**——反客为主 |

**附：支临干的另外三种情形**

| 支临干而…… | 名 | 断 |
|---|---|---|
| **生干** | 自在 | 坐享 |
| **受干生** | 求受 | 反竭我力 |
| **与干同类** | 壮基 | 并国相济 |

> ⚠️ 若**支上乘脱气**，原书说「必无正屋可居，终非自立之象」——占住处、占能不能自立时，这条比象曰更管用。

**讲义（六十四课经）**

> 「赘婿支临干被克，干加支上克支通。」
> 〔讲义·课目总歌〕

| | |
|---|---|
| **怎么成格（讲义）** | 凡课，日干克辰，又自加临为用，曰赘婿课。 |
| **归类** | 动阻隐伏 |

## 5. 冲破课

| | |
|---|---|
| **怎么成格** | **日辰的冲神、加在破位上发用**；或用神与岁月日时相冲破 |
| **卦体** | 统「夬」之体——**雪上加霜** |
| **一句话** | **先动摇，再散架** |

> 「凡课，日辰之冲神，加破为用，曰冲破课。**冲者，动摇也。初虽有德，后必倾覆**。」
> 「**破者，解散也**，主事更改，多有中辍……盖**冲主反复，破主倾坏**，冲破凶为一类，故名冲破。」
> 〔通解中 p381｜PDF p17〕

**象曰**

> 「人情反复，门户不宁。婚姻不遂，胎孕难成。疾病凶散，财利事平。**凡有谋望，成而复倾**。」
> 〔通解中 p381｜PDF p17〕

**六冲各主什么**（这张表单独拿出来也好用）

| 冲 | 断 |
|---|---|
| **子午** | 道路驰逐，男女争谋变动 |
| **卯酉** | 门户改移，或逃亡失脱，外人淫乱奸私 |
| **寅申** | 人鬼相伤，**夫妇异心** |
| **巳亥** | 事反复无实，**重求轻得** |
| **丑未** | 兄弟兴衰相持，谋心不同，干事不遂 |
| **辰戌** | 主仆离异，贵贱不明，不义之争 |

**破各主什么**

| 破 | 断 |
|---|---|
| 午破卯、酉破子 | 门户破败，阴小有灾 |
| 辰破丑 | 丘墓寺观破损 |
| 戌破未 | **先破后刑** |
| 亥破寅、申破巳 | **先破后合** |

**⭐ 冲不是一味的坏——四句口诀**

> 「此课**旺不宜冲，衰墓宜冲；吉不宜冲，凶将宜冲；凶空不宜冲，吉凶宜冲**。类神空亡，岁月冲则**暗动**，日辰次之。**破不宜望成事，宜散凶事**。」
> 〔通解中 p382｜PDF p18〕

> 〔存疑〕《订讹》末一句作「**吉凶宜冲**」，与它前半句「凶空不宜冲」对不上——正文另一处说的是「**吉空宜冲，凶空不宜冲**」〔通解中 p381｜PDF p17〕，按那处理解才通顺。**两处字面都照录，不替它改**。

| 什么状态 | 该不该冲 |
|---|---|
| 旺相 | **不宜**冲（冲动则为凶） |
| 衰、墓 | **宜**冲（冲开才活） |
| 吉神吉将 | **不宜**冲 |
| 凶将、死神丧车恶杀 | **宜**冲（冲散则不成争） |
| **吉神落空** | **宜**冲（冲则反实） |
| **凶神落空** | **不宜**冲（冲实了反而成真） |

> 💡 「**冲则反实**」是六壬很要紧的一条：空亡的字被冲，反而变成实的。所以**吉空要冲、凶空怕冲**——这条和第 7 课的旬空、第 16 课的应期都接得上。

## 7. 芜淫课

| | |
|---|---|
| **怎么成格** | **四课有克但缺一课**（不备），或**日辰交互相克** |
| **卦体** | 统「小畜」之体——**琴瑟不调** |
| **一句话** | **夫妻各有各的心思** |

> 「凡见**二阳一阴为阴不备**，如二男争一女。**二阴一阳为阳不备**，若二女争一男。及日辰交互相克，各自相生是也。此**夫妻皆有私通，两情相背，荒淫无度**，故名芜淫。」
> 〔通解中 p386｜PDF p22〕

**象曰**

> 「阴阳不备，交克最嫌。利名碌碌，狱病淹淹。阴微晴久，阳少雨添。行人未至，征战愁占。」
> 〔通解中 p386｜PDF p22〕

**⚠️ 怎么数"缺一课"——最容易错的一步**

> 「课得不备，**刚日从日上起第一课，柔日从辰上起第一课**。」
> 〔通解中 p386｜PDF p22〕

《订讹》把道理讲透了：第一课是干阳、第二课是干阴、第三课是支阳、第四课是支阴——

> 「盖第一课为干阳，第二课为干阴，第三课为支阳，第四课为支阴。**阴课缺一为阴不周全，阳课缺一为阳不周全。以四课之阴阳论，非以干支之阴阳论也**。」
> 〔通解中 p388｜PDF p24〕

> 💡 关键在于**一个上神只能占一个位子**。乙卯日午时未将，巳辰既然已经当了支的阴神（第二课），就**不能再拿去当干的阳神**（第三课）——于是四课只剩三课，这才叫"不备"。数错的人多半是把同一个上神数了两遍。

**阴不备与阳不备，断法相反**

| | 怎么成 | 断 | 兵家 |
|---|---|---|---|
| **阳不备** | 二阴一阳 | **二女争一男** | 利为主，**贼不来** |
| **阴不备** | 二阳一阴 | **二男争一女** | 利为客，**贼必来**，但战不成 |

**通用断**

> 「占主不周全，物偏缺，病难愈，求望难成，行人未至……**三传阳多，事起男；三传阴多，事因女**。阳多晴久，阴多雨添。凡占多以不周全为断。」
> 〔通解中 p388｜PDF p24〕

**翻盘的条件**

> 「或**四课备、神将吉兼有救神**，及**课不备、无克不凶**，事有迟延，**夫妻拆散终复团圆**。」
> 〔通解中 p386｜PDF p22〕

> ⚠️ **「芜淫」是象，不是判词**。中册自己的案例里就为这个吵过一轮——占雇工得芜淫，断的是"两主争一仆"而不是男女私情。原书按语说得很直：

> 「凡课须识得一象字，如《毕法》云：『夫妻芜淫各有私』，**此象也，非死局也**。须看所占何事。**如占家宅夫妇可断芜淫，若宾主往来交际，亦曰两男争一女乎？**」
> 〔通解中 p377｜PDF p13〕

**讲义（六十四课经）**

> 「芜淫三课有克取，交车克下男女争。」
> 〔讲义·课目总歌〕

| | |
|---|---|
| **怎么成格（讲义）** | 凡四课有克，缺一为不备；及日辰交互相克，为芜淫课。 |
| **归类** | 动阻隐伏 |

〔出处〕讲义中册·第五章

## 8. 解离课

| | |

| **怎么成格** | **夫妻行年上下互相冲克**；或干支上神互相克贼 |

**⭐ 和芜淫课怎么分**（这是两格最容易混的地方，原书专门交代过）

| | 克的是什么 |
|---|---|
| **芜淫** | 干支的**上神去克下** |

| 年命互相克 | **两格都算** |

**《毕法》给的判定**

> 「**真解离卦者，谓干克支上神，支克干上神**。或夫妇行年又值此者尤的。此时占人必占解离事。」
> 〔通解中 p391｜PDF p27〕

**歌诀**

> 「夫妻天匹配，有难解离频。**年命交相克**，始终亦同陈……**递相淫情起，暗地使媒人**。」
> 〔通解中 p390｜PDF p26〕

> 〔通解中 p391｜PDF p27〕

## 11. 无禄课 / 绝嗣课

| | |
|---|---|
| **怎么成格** | **四上俱克下**＝无禄；**四下俱贼上**＝绝嗣 |
| **卦体** | 统「否」之体——**上下僭乱** |
| **一句话** | **上下彻底翻脸**，比度厄更绝 |

> 「凡课**四上俱克下，为无禄课**。盖日神阴阳俱相克，不得其所，不免投辰上两课，辰上阴阳又相克，**则无所投之路**，占者多主孤独。」

**两格对照**（断法几乎处处相反，别记混）

| | **无禄**（四上克下） | **绝嗣**（四下贼上） |
|---|---|---|
| 义 | 上不容下，为**不恕** | 下不敬上，为**不忠** |
| 断 | 庶人不禄；**有官罚职**，轻则罚俸，重则削职 | 小人无礼、暗算、横灾殃祸 |
| 病 | 病必死 | 病者易死 |
| 事起于 | **女人** | **男子** |
| 兵讼 | **后者胜**（宜后对） | **先者胜**（宜先起） |
| 动静 | **静而必动** | **动而必静** |
| 六亲 | 孤独失业，多刑伤 | 尊长见灾，奴婢逃，骨肉散 |

> ⚠️ 《订讹》与正文在"兵讼谁胜"上给的是**相反的说法**——正文说无禄「对敌利客，讼宜先起者胜」〔通解中 p397｜PDF p33〕，《订讹》说无禄「兵讼后者胜」〔通解中 p398｜PDF p34〕。**两说并列，不替你选**；实占时以年命、救神的向背为准。

**⭐ 救神怎么找**（这一格的救最要紧，《观月经》注解讲得最细）

> 「四课俱临下者，为无禄卦。**如发用是水神，末传得金神为救。发用是金神，三传见土神为救神**……虽是无禄卦，不言绝也。」
> 〔通解中 p398｜PDF p34〕

**救神＝生发用的那一行**（金生水、土生金）。三传里能接上这一环，凶格就不作绝断。

> 💡 绝嗣课的救法同理：己未日四下贼上、三传巳戌卯，「初巳火发用，与今日己土比合，中传戌土为子孙，末传卯木为父母，**不得言绝嗣，为有救也**」。〔通解中 p399｜PDF p35〕

## 22. 励德课

| | |
|---|---|
| **怎么成格** | **天乙贵人立于卯或酉** |
| **卦体** | 统「随」之体——**反复不定** |
| **一句话** | **君子进、小人退**——一格分贵贱 |

> 「盖**卯酉为阴阳交易之位，贵人由之而迁易**……此天道福善祸淫，**奖励有德**，占**利君子不利小人**。」
> 〔通解中 p445｜PDF p81〕

**象曰**

> 「**阳神前引，阴神后随。君子则吉，小人则危。阴神前立，阳神后居。小人得意，君子失机**。」
> 〔通解中 p445｜PDF p81〕

**⭐ 三个格，看阴阳神在贵人的前还是后**

| 阴阳神的位置 | 格名 | 断 |
|---|---|---|
| **阳神在贵人前**（贵人得引） | 励德（正格） | **君子进用**，小人退剥 |
| **阴神在贵人前**（贵人受羁绊） | 励德（反面） | **小人得意，君子失机** |
| 阴阳**俱在贵人后** | **微服格** | **君子迁官，小人退职**；事体稍迟，**大干则可，小处不可** |
| 阴阳**俱在贵人前** | **蹉跎格** | **小人进职，君子退位**；事体稍迟，**小处则可，大干不可** |

> 💡 **「大干则可，小处不可」这一对反着来**，是微服与蹉跎最实用的分别：微服格宜办大事、蹉跎格只宜办小事。

**两条现成断语**

> 「**阴在贵人前，讼则卑遭责。阳在贵后，灾则修德自愈**。」
> 〔通解中 p445｜PDF p81〕

> ⚠️ 原书自己都说这一格讲不清楚：「**此课通龟与《订讹》皆说不明**，止曰日辰阴神在天乙前……」〔通解中 p447｜PDF p83〕——遇到励德课，**以"贵人被引还是被绊"这个大方向为准**，细分的三格各家说法本就有出入。

**讲义（六十四课经）**

> 「励德日辰看前后，天乙立在二八门。」
> 〔讲义·课目总歌〕

| | |
|---|---|
| **怎么成格（讲义）** | 凡天乙立卯酉，为励德课。 |
| **归类** | 综合取象 |

**象曰**

> 「阳神前引，阴神后随。君子则吉，小人则危。阴神前立，阳神后居。小人得意，君子失机。」
> 〔讲义 p179〕

**术语**　卯酉为阴阳交易之位、日月之门，贵人由之而迁易。所谓前后指天将，非论日辰；天乙居中，后六前五。

**断诀**

- 统「随」之体，乃反复不定之课。
- 阳神前引、阴神后随：君子进用，吉。
- 阴神前立、阳神后居：小人得意，君子失机，凶。
- 阳在阴位(天乙后)今当进上；阴在阳位(天乙前)今当黜下。占人贵者将迁、下吏罢退；庶人居宅不安，宜谢土神。

**变格**

- 微服格：日辰阴阳俱在天乙后 → 君子迁官、小人退职，事体稍迟，大干可、小处不可。
- 蹉跎格：日辰阴阳俱在天乙前 → 小人进职、君子退位，小处可、大干不可。

〔出处〕讲义 p179

## 23. 盘珠课

| | |
|---|---|
| **怎么成格** | **太岁、月建、日、时及三传全在四课之中** |
| **卦体** | 统「大壮」之体——**凤翔丹山** |
| **一句话** | **该到的全到齐了**，珠子不出盘 |

> 「如甲子年七月乙巳日酉时已将占，**岁月日时皆在四课之上，为天心格**。主事远大非常，及干朝廷，可以成就。如辛亥日占，三传戊酉申，**皆在四课之上，为回还格**，主谋为得遂，吉凶之事皆成。此二格合一，**如盘中走珠，不出于外**，故名盘珠。」
> 〔通解中 p449｜PDF p85〕

> 〔存疑〕这段例子里有两个讹字，**照录未改**：「酉时**已**将」当作「**巳**将」（月将不作"已"）；「三传**戊**酉申」当作「**戌**酉申」（戊是天干，不入三传，且戌酉申正是逆连的三传）。

**象曰**

> 「三传四课，偶合异常。**吉则成福，凶则成殃**。贼不出境，行人还乡。**阴私解释，事反不良**。」
> 〔通解中 p449｜PDF p85〕

**⚠️ 这是本篇里最需要分事看的一格**

| 占什么 | 断 |
|---|---|
| 干求、谋望、行人、追贼 | **大吉**——事远大非常，可干朝廷 |
| **病讼、生产、忧疑、要求解脱的事** | **反凶**——想散的事偏偏散不掉 |

> 💡 道理就在"珠不出盘"四个字：**要成的事它成，要散的事它也散不了**。所以占解脱、占病愈，盘珠是坏消息。

## 24. 玄胎课

| | |
|---|---|
| **怎么成格** | **孟神发用，三传皆四孟**（寅申巳亥） |
| **卦体** | 统「家人」之体——**开花结子** |
| **一句话** | **什么都在刚起头** |

> 「盖四孟者，寅申巳亥，**四生之局**，又为五行受气之位……此**玄中有胎**，故名玄胎。**占者事皆新意**。」
> 〔通解中 p462｜PDF p98〕

**象曰**

> 「三传长生，胎孕成形。官加恩爵，婚获娉婷。**病讼淹滞**，财利迭兴。行人敌贼，**恋生不行**。」
> 〔通解中 p462｜PDF p98〕

**⭐ 进步长生与退步长生（这一对最要紧，而且原书两处说法打架）**

| 三传走向 | 名 | 断 |
|---|---|---|
| **寅加巳、巳加申、申加亥、亥加寅** | **进步长生**（又名**病胎**） | 上生下，为五行病处，**怀胎有忧** |
| **寅加亥、亥加申、申加巳、巳加寅** | **退步长生**（又名**生胎**） | 下生上，身临长生之乡，**怀胎大吉** |

> 〔存疑〕**事速还是事迟，两处相反**：正文说「寅加巳……为进步长生，**主事迟**」〔通解中 p462｜PDF p98〕，《订讹》说进步长生「**主事速**」、退步长生「主事迟」〔通解中 p463｜PDF p99〕。**两说并列，不替你选**；但"病胎／生胎"的吉凶两处一致，占孕以那条为准。

**⭐ 占孕的现成断语**

> 「如**用值天后财爻，主妻必怀胎**。外有**妻财值生气、胎神发用**，主妻有孕。如**正月戊己日用子，四月庚辛日用卯，七月壬癸日用午**，占妻怀孕无疑。**或年命见之，遇玄胎尤的**。」
> 〔通解中 p462｜PDF p98〕

**几条反面**

| 盘上 | 断 |
|---|---|
| **老少占病** | **后世投胎之兆，最凶** |
| 遇三刑及凶神恶将 | 必有忧疑惊恐 |
| **父母**用事 | 家中尊长见灾 |
| **子孙空亡** | **玄胎不育**，凡占无成，更艰子息 |
| **天后空亡** | 因孕**伤母** |
| 日用休囚、天后落空 | 玄胎不育，家招**干儿女**接续 |
| **返吟课** | 为**绝胎** |

> ⚠️ 玄胎虽是喜庆之兆，原书提醒「**多身喜心忧**」——"盖为腹中有孕，心自悬悬也"。而且「事主远而多伏，暗昧不通，**触则成祸**」。〔通解中 p463｜PDF p99〕

> 「玄胎三传皆四孟，玄中有胎名义深。」
> 〔讲义·课目总歌〕

| | |
|---|---|
| **怎么成格（讲义）** | 凡孟神发用，传皆四孟，为玄胎课。 |

## 25. 连珠课

| | |
|---|---|
| **怎么成格** | **三传在一方相连**（如寅卯辰） |
| **卦体** | 统「复」之体——**山外青山** |
| **一句话** | **一件接一件，停不下来** |

> 「盖中末传**孟仲季神相连若贯珠**，故名连茹……**吉事占之，若连珠可爱；凶似连茹可恶**。」
> 〔通解中 p465｜PDF p101〕

**象曰**

> 「阴阳拱夹，奇偶有主。**凶则重重，吉当累累**。孕必连胎，事获交举。时旱多晴，天阴久雨。」
> 〔通解中 p466｜PDF p102〕

**⭐ 进退与空亡的四种组合**（这一段是连珠课的核心用法）

| 三传 | 遇空亡 | 该怎么办 |
|---|---|---|
| **进连珠**（顺行） | 不空 | **宜进**——贵顺、事顺、速成 |
| **进连珠** | **值空亡** | **宜退**——可以全身远害 |
| **退连珠**（逆行，又名**失友格**） | 不空 | **宜退**——贵逆、迟阻 |
| **退连珠** | **值空亡** | **宜进**——可以消灾避祸 |

> 💡 **空亡把方向反过来**——这是连珠课最见功夫的一条：顺着走的盘一落空就该退，倒着走的盘一落空反而该进。

**三奇联珠**：三传**亥子丑**、日月星三奇全者，主万事合和，乘吉将尤吉。〔通解中 p465｜PDF p101〕

### 附：夹定三传的几个格（连珠课常带出来）

| 盘上 | 名 | 断 |
|---|---|---|
| 日辰**前后夹定**三传 | **夹定三传格** | **进退皆不由人**；病讼解除不利，**财喜与成合之事则美** |
| 夹定但**少一位** | **夹定虚一格** | 事有小节不完；**前虚一**主初时有阻，**后虚一**主将成小阻。虚的那一位是什么，就是哪方面不足（是日财则财上不足，是父母则长上不足） |
| 三传**透出日干之外** | **夹不住格** | 「**夹住不住，留中有去**」——进透出是进得太过，退透出是退得不及 |
| 支上发传**朝日** | **朝日格** | 神吉传吉：成合之事**不求自至**；神凶传凶：**祸来不测**，占病与生产忌 |
| 三传**归支上** | **朝支格** | 如臣使君、子使父，**俯就于人，被人抑勒不自由**；旺相尤可，死囚更凶，**利卑不利尊，利静不利动** |

> ⚠️ 「若**干透出支，不利外动事，有回还；支透出干，不利于内，惟宜外动**。**或透鬼，鬼在外，有凶；透财，财在外，有破耗**。」〔通解中 p466｜PDF p102〕

**讲义（六十四课经）**

> 「连珠联茹兼进退。」
> 〔讲义·课目总歌〕

| | |
|---|---|
| **怎么成格（讲义）** | 凡用神传在一方，相连作中末，为连珠课。 |
| **归类** | 综合取象 |

**象曰**

> 「阴阳拱夹，奇偶有主。凶则重重，吉当累累。孕必连胎，事获交举。时旱多晴，天阴久雨。」
> 〔讲义 p186〕

**术语**　又名连茹。三传在一方相连若贯珠，如寅卯辰之类。

**断诀**

- 统「复」之体，乃山外青山之课。吉事占之若连珠可爱，凶则似连茹可恶。
- 占主吉凶各重迭不已：进连珠事顺，退连珠事逆。
- 传进宜进，贵顺事顺速成；值空亡则宜退，可以全身远害。
- 传退宜退，贵逆迟阻；遇空亡则宜进，可以消灾避祸。

**变格**

- 退连茹(失友格)：主事欲行不行，人情欠美。
- 三奇联珠：三传亥子丑，日月星奇全 → 万事合和，乘吉将尤吉。

| **归类** | 吉庆贵显 |

**象曰**

> 「顽金铸篆，藉火功全，官职高擢，诏命重宣，产孕大吉，干谒良缘，庶人不吉，疾病官愆。」
> 〔讲义 p140〕

**术语**　戌为天魁(印)、巳为太乙(炉)、卯为太冲(印模/轩车)、太常为绶。

**断诀**

- 统「颐」类革故鼎新之意；核心原理是金火相济，全凭火炼方铸成贵器(符印)。
- 吉：占科举、求官、见君王、进策，主官爵高迁、符命入手。需得驿马、太阳、六合为真体。
- 凶：春夏巳午日时火旺，或印神值空亡、月破，为「破印损模」，事终不济。
- 庶人占之反主官灾刑害；末传见天后、玄武临水乡破日，名「铸印不成」，主望官中阻。

**变格**

- 破印损模：火太旺或印神空破，事终不济。
- 铸印不成：末传天后/玄武临水乡破日，望官中阻。
- 乘日墓：主退失，或旧事再新。

> ⚠️ ✅ 存疑已澄清：讲义三处两说——p140 与课目总歌 p113 作「戊加巳／已」，p77 简明定义作「铸印卦：戌加巳发用」。决定性论据是术理：六壬天盘只有十二地支，天干「戊」根本上不了盘，「戊加巳」在任何课式里都不可能出现；加之 p140 象意自释「戌：印」。故定为「戌」，本站按此判。

| **上下翻脸** | 乱首、赘婿、度厄、无禄绝嗣、殃咎 | 讲**尊卑秩序**乱了，差别只在乱的程度与方向 |
| **男女之事** | 三交、淫泆、芜淫、解离、龙战、九丑 | 讲**私情与离散**，都要看卯酉与后合 |
| **伤与丧** | 侵害、刑伤、冲破、魄化、死奇、灾厄、鬼墓、天网 | 讲**克伤**，区别在克的方式（害/刑/冲/虎/罡/煞/墓/网） |
| **贵贱进退** | 励德、盘珠、孤寡 | 讲**位置与得失**，君子小人各断各的 |

> ⭐ 真正要背的其实只有每格的**成格条件**——断意都能从"这个格凶在哪儿"推出来。查的时候倒过来用：**先看盘上有什么特征，再翻到对应那一格看断语**。
