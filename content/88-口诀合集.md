## 十二天将

### 天乙贵人

五行：土  
类象：官贵、文书、解厄、贵人扶持  
断法：临身最吉；空亡或受克则无力  
昼主公开阳事，夜主隐秘阴情  
地位：十二天将之首，以贵人定顺逆行序

### 螣蛇

五行：火  
类象：惊恐、怪异、火灾、缠绕、梦魇  
断法：逢吉神吉中带扰；逢凶神灾祸缠身  
空亡：螣蛇空，诸凶可免  
特征：主心神不宁，事多反复纠缠

### 朱雀

五行：火  
类象：口舌、文书、信息、诉讼、官司  
断法：临日干主口舌；临财官主文书喜庆  
空亡：朱雀空，口舌消散  
特征：南方火鸟，主言语文字一切信息传递

### 六合

五行：木  
类象：婚姻、交易、中介、合作、和合  
断法：占婚最喜；占失物主被藏匿或交易所得  
空亡：六合空，婚约不成  
特征：主和合成交，事事喜六合临

### 勾陈

五行：土  
类象：田土、牢狱、争斗、迟滞  
断法：主田产纠纷、官司牢狱、事体拖延  
空亡：纠纷可解，事不成  
特征：勾连纠缠，主延误与争讼

### 青龙

五行：木  
类象：财帛、喜庆、升迁、酒食  
断法：大吉之神，主财利升官嫁娶  
空亡：青龙空，财喜减半  
特征：六壬最吉之将，临则百事顺遂

### 天空

五行：土  
类象：虚诈、空亡、僧道、遗失  
断法：主事体落空、虚诈不实；占财谋事多不成  
特征：天空者虚无落空，遇之防欺诈

### 白虎

五行：金  
类象：血光、死亡、疾病、丧事  
断法：大凶之神，主伤灾疾病丧亡  
空亡：白虎空，见凶不凶  
特征：六壬最凶之将，逢吉神可解，逢凶加剧

### 太常

五行：土  
类象：酒食、宴饮、服饰、官职  
断法：主饮食喜庆官职；占婚主婚礼  
空亡：太常空，喜事减半  
特征：礼仪之神，主官场礼遇与饮食之事

### 玄武

五行：水  
类象：盗窃、欺诈、暧昧、遗失  
断法：主失窃被骗暧昧；占失物主被盗  
空亡：玄武空，谋害不凶  
特征：北方水神，主阴暗隐秘，盗诈之事

### 太阴

五行：金  
类象：阴私、隐匿、妇女、阴谋  
断法：主暗中谋划、阴私之事；占婚主私情  
特征：月亮之神，主隐秘幽暗，女性阴私之象

### 天后

五行：水  
类象：妇女、婚姻、生育、雨水  
断法：主妇女之事婚姻生育；占婚主女方  
特征：后宫之主，主婚姻生育，占孕产最重此将

## 遁干口诀

### 五虎遁月（年上起月干）

甲己之年丙作首  
乙庚之岁戊为头  
丙辛之岁寻庚上  
丁壬壬位顺行流  
若问戊癸何方发  
甲寅之上好追求  
  
用法：以年干查得寅月天干，顺推至所求月份

### 五鼠遁时（日上起时干）

甲己还加甲  
乙庚丙作初  
丙辛从戊起  
丁壬庚子居  
戊癸何方发  
壬子是真途  
  
用法：以日干查得子时天干，顺推至所求时辰

### 十干寄宫口诀

甲课寅兮乙课辰  
丙戊课巳不需论  
丁己课未庚申上  
辛戌壬亥是其真  
癸课原来丑宫坐  
分明不用四正神  
  
用法：排四课时，以此确定日干在地盘的寄宫位置

### 遁干分布（六旬起法）

甲子旬起甲子（子时甲）  
甲戌旬起甲子→实为壬子（差两位）  
速记：五旬对应五鼠遁  
甲己→甲子起

## 九宗门

### 元首课

特征：一上克下（天克地）  
发用：取克下之上神为初传  
象意：天象，君驭臣，名正言顺，九宗之首  
断法：事从外来，宜进取，吉多于凶

### 重审课

特征：一下克上（地贼天）  
发用：取受克之下神为初传  
象意：地象，臣谏君，宜审慎  
断法：事从内起，主慎重，发难之端

### 比用课

特征：二或四课交相克  
发用：取与日干阴阳相比者（阳日取阳，阴日取阴）  
二下贼上→比用；二上克下→知一  
断法：事多纠纷，阴阳有别，需明辨立场

### 涉害课

特征：多克且阴阳不比，顺数本家统计克害  
发用：取克害次数最深者  
相等取法：有孟取孟（见机）→ 有仲取仲（察微）→ 复等：阳日取干上，阴日取辰上  
断法：涉险而过，步步为营

### 遥克·蒿矢

特征：四课无正克，他课上神遥克日干  
发用：取遥克日干之上神为初传  
象意：蒿矢者，以草作箭，力微，被动受击  
断法：利客不利主，宜守不宜动

### 遥克·弹射

特征：四课无正克，日干遥克他课上神  
发用：取被日干遥克之上神为初传  
象意：弹射者，主动出击，力强  
断法：利小不利大，主动则吉，利主不利客

### 昴星课

特征：无克无遥克，四课完备  
发用：取地盘酉位（从魁）上神为初传，不分阴阳日  
断法：一切茫然，无迹可寻，凭感觉行事，宜问神

### 别责课

特征：柔日（阴日），四课无克无遥克，二三课相同  
发用：初传取日支前三合之神；中末传均取日上神  
断法：主事不全，责任不清，宜分工明确

### 八专课

特征：干支同位，仅两课  
发用：有克按克法；无克刚日顺数三位，柔日逆数三位；中末取日上神  
断法：主混杂宣淫，一人独断，事体偏颇

## 取用神·六亲

### 六亲总纲·以日干为我

取用第一步：定日干为"我"，按五行生克认六亲：  
生我者 → 父母（庇护、文书、房宅、长辈）  
我生者 → 子孙（子女、下属、医药、僧道）  
克我者 → 官鬼（官职、官司、疾患、盗贼、夫）  
我克者 → 妻财（钱财、妻妾、食物、田产）  
同我者 → 兄弟（兄弟、朋友、同辈、竞争）  
  
※ 六亲只定"名分"，占具体人事还须并看类神与天将（见下）。

### 人类神·父母与妻

【原文】父母生气与日本，父兼德神母天后；妻责天后并财爻，神后之神亦为取。  
【解】  
占父母 → 取"生我"之爻（生气）与日干本气；父再看日德，母再看天后。  
占妻 → 取天后、财爻、神后（子）三者。

### 人类神·兄弟与子孙

【原文】兄弟姊妹责太阴，及兼兄弟之爻神；子孙六合子孙爻，太冲登明亦可寻。  
【解】  
占兄弟姊妹 → 取太阴，并看"同我"之兄弟爻。  
占子孙 → 取六合、子孙爻，太冲（卯）、登明（亥）亦可取。

### 人类神·奴婢与朋友

【原文】奴责河魁及天空，婢责从魁太阴中；朋友单来责六合。  
【解】  
占奴仆 → 河魁（戌）、天空。  
占婢女 → 从魁（酉）、太阴。  
占朋友 → 六合。  
※ 以上为"人之类神"：占某人，先定其类神落在盘中何处。

### 事类神·求官与求名

【原文】求官龙常及官星，求名文书朱雀中。  
【解】  
求官职 → 取青龙、太常，并看官星（官鬼爻）。  
求功名文书 → 取文书爻、朱雀。  
※ 案例中"青龙乘官""朱雀发用"即由此断。

### 事类神·婚姻求财谒见

【原文】干贵贵人婚天后，求财青龙财交通。  
【解】  
谒见贵人／求人 → 取贵人。  
占婚姻 → 取天后（并看六合为媒）。  
求财 → 取青龙与财爻。

### 事类神·衣食雨晴田土路

【原文】衣服酒食责太常，雨责青龙晴天空；田土勾陈路白虎。  
【解】  
衣服酒食 → 太常。  
占雨 → 青龙；占晴 → 天空。  
田土 → 勾陈；道路 → 白虎。  
※ 以上为"事之类神"：占某事，先认取该事之神。

### 取用总法·兼二三以入传课

【原文】人事类神兼二三，以入传课为取用。若是皆入皆不入，不用兼神责将神。如妻止去责天后，财爻神后不须论。  
【解·最关键】  
一事的类神常有两三个，优先取"已入三传/四课"者为用神；  
若几个都入或都不入，则不用兼神，直取本将（如占妻只取天后，财爻神后可不论）。

### 用神旺衰定成败

【原文】不在课传为局外，所临地位看原因。有气亦远无气难，旺相德合终可亲。  
【解】  
类神不入课传 → 属"局外"，看它所临地盘定缘由；  
用神有气 → 事虽远亦可成；无气 → 难成；  
旺相＋逢德合 → 终究可成。  
※ 这一句是"取用神之后如何定吉凶"的总纲。

### 遁干起法与旬空

【原文】遁干采旬遁法，据日干所属甲子旬排三传天干。  
【解】  
三传只有地支，须"遁"出天干才能论六亲：  
以日所在旬（甲子/甲戌…甲寅），用五鼠遁起子时干，顺数到三传各支，得其遁干。  
遁干与日干的生克 → 定该传的六亲属性；旬中所缺二支即旬空。

## 三传断法

### 初传

象意：事之始，发端，来意  
别名：先锋门  
断法：定事件起点与来因；断来意关键  
生日干→事吉，主动有利  
克日干→事凶，被动不利  
入空→事无头绪，虚头

### 中传

象意：事之变，转折，过程  
断法：看事情发展中的变化  
初生中→吉转吉，顺利推进  
初克中→受阻，发生转变  
中克初→过程生波折  
入空→中途落空，转机难寻

### 末传

象意：事之终，结果，归宿  
断法：定最终结果  
末生日干→结果吉，事终成  
末克日干→结果凶，事终败  
末入空亡→虎头蛇尾，终不成  
末合日干→和合收场

### 三传顺生

特征：初→中→末依次相生  
断法：事体顺遂，一帆风顺，吉上加吉  
口诀：三传如链，节节相生，所谋皆成  
注意：三传顺生为六壬最吉之象之一

### 三传逆克

特征：初→中→末依次相克  
断法：阻碍重重，节节受制，凶上加凶  
口诀：三传克制，须防反复受损  
注意：逆克与逆生（倒生）不同，需仔细辨别

### 回头生克

回头生：末传生初传  
→首尾呼应，始终有成，到底成事  
回头克：末传克初传  
→虽起点好，终受克制，始吉终凶  
断诀：回头生，到底成；回头克，始吉终凶

## 行年法

### 本命定义

本命：求占者的出生年干支。  
例：1984 年生，查万年历为甲子年，甲子即其本命。  
  
本命为体（静），终身不变。  
六壬判断有时需加入本命合参，但这不是固定步骤——预测以预测者本身为太极，要素取舍在于自己，不可被课式拘泥。  
  
年命称「变体门」：课吉而年命凶，吉象被制化为凶；课凶而年命吉，凶象被制化为吉。

### 行年定义

行年：求测者当年所处的流年干支，也叫「岁运」「小运」。  
  
本命是体，行年是用；课式是体，本命行年是用。  
  
古人认为天开于子、地辟于丑、而人生于寅，所以——  
男子行年：一岁从丙寅开始，顺行；  
女子取阴阳对待之义：一岁从壬申开始，逆行。  
  
注意：起点是干支（丙寅/壬申），不是本命年支。

### 男命行年（丙寅顺行）

男命：一岁丙寅，此后按六十甲子顺推。  
一岁丙寅 · 二岁丁卯 · 三岁戊辰 · 四岁己巳 · 五岁庚午  
六岁辛未 · 七岁壬申 · 八岁癸酉 · 九岁甲戌 · 十岁乙亥  
十一岁丙子 · 十二岁丁丑……  
六十一岁又从丙寅起，周而复始。  
  
速算：虚岁 n 的行年 = 六十甲子第 (n+1) 位（甲子记为第 0 位）。

### 女命行年（壬申逆行）

女命：一岁壬申，此后按六十甲子逆推。  
一岁壬申 · 二岁辛未 · 三岁庚午 · 四岁己巳 · 五岁戊辰  
六岁丁卯 · 七岁丙寅 · 八岁乙丑 · 九岁甲子 · 十岁癸亥  
十一岁壬戌 · 十二岁辛酉……  
六十一岁又从壬申起，周而复始。  
  
速算：虚岁 n 的行年 = 六十甲子第 (9 − n) 位（不足则加 60）。

### 行年推算·课例验算

讲义课例：丁亥年（2007）占，占人戊午命，行年乙未。  
  
验算（男命）：  
戊午年生 = 1978 年  
虚岁 = 2007 − 1978 + 1 = 30  
六十甲子第 (30+1) = 第 31 位 → 乙未 ✓  
  
提示：若按「本命年支起、每年推一步」推算，午支推 29 步得亥，与讲义不符——起点必须是丙寅/壬申。

### 行年应用（讲义）

行年上神旺相为吉，得吉将更妙；带休囚全都转凶，遇凶将尤甚。  
日干克行年上神为大凶；行年克日干上神也不是吉兆。  
年与日相合比德皆吉，但谋求文书之事主迟滞不快意。  
行年与日生合亦吉，带吉神更好；行年与日相刑克反凶。  
行年与用传相生合则吉，相克则大凶。  
行年落空亡不利：旺相尚可，休囚则主凶。

### 本命应用（讲义）

命克日干→凡事都不顺。  
日干克命→只适宜求官。  
命克用神→凡事都不能成功。  
用神克命→主会有灾祸悔恨。  
命上神与日上神相生→主有喜事；逢旺相而克制→主有忧愁之事。  
命上见吉将则吉，见凶将则凶。  
命上见太岁相生→主一年中吉利；相刑→主中等凶险，常人主官府带来的忧虑猜疑。

### 行年断诀

日上神克命上神→求财速成，带喜马德禄主功名  
命上神克日上神→官符灾讼，病厄临身  
日上神合命上神→喜事自生，好事连连  
日克年神→行人病在中途  
年神克日→诸事受阻，骨肉灾伤  
贵带吉神临命→解忧转运，否极泰来  
螣蛇生年→有人扶翼；克年→惊恐多

## 支神总口诀

### 子午 —— 阴阳交替的位置

子为一阳之始，午为一阴之始。

断用：凡事到子午，多主局面翻转、由盛转衰或由衰转盛。

日出于卯，月出于酉，故卯酉为门户之神。  
  
断用：主门户、出入、开合、私门暗地。占宅看门向，占事看能否出入通达。

寅申为四孟之二，主动而行远。  
  
断用：主道路、行程、往来、交通、驿动。占行人、占出行必看寅申。

### 亥巳 —— 天门地户

亥为天门，巳为地户，又叫「天涯海角」。  
  
断用：主极远、极端、始终两头。事到亥巳，多主远行、远方消息，或事情走到尽头。

### 辰戌 —— 天牢地狱

辰为天罡、戌为河魁，二者皆土，为魁罡之地。

## 空亡断诀

### 空亡总论

空亡：旬中无干之二支，力减半或全空。  
旺相：空而有气，减力；休囚：空而无气，全空。  
断则：吉神入空→吉减半；凶神入空→凶可免。  
用神入空→事不成，虎头蛇尾；支入空→妻财有损；命入空→身体虚弱。  
古诀：空亡减半，披刑带煞灾病立至。

### 贵人入空

"贵入于空，干贵反凶。当谒莫谒，当逢莫逢。"  
→ 贵人能解祸生福，若入空则不得力。  
  
"贵入于空，求名虚声，传入二死，不善其事。"  
→ 中末入二死，慕功名终身无成；若逢生助，后犹有望。  
  
"贵雀作鬼，入于空亡，文字贵物，乃是其赃。"  
→ 用乘贵雀空鬼，文书贵物乃赃，余以神煞详之。

### 螣蛇入空

"蛇入于空，可免诸凶。任尔出入，自迪其功。"  
→ 螣蛇凶将入空，诸凶可免，出入有功。  
  
"螣蛇作鬼，入于空亡，惊惶走失，又作火类。"  
→ 用虽入空，不免惊惶，走失火光之事。  
  
要点：螣蛇最喜入空，变凶为吉的特例。

### 朱雀入空

"朱入于空，望文不就，执不如舍，进则难售。"  
→ 朱雀为文书，入空虽旺不就，不如别谋，是非口舌则免。  
  
"朱雀作鬼，入于空亡，不无虚诞，信息为狂。"  
→ 空鬼雀，信息虚诞、口舌无实。  
  
要点：占文书信息，朱雀入空则消散。

### 六合入空

"六合入空，求财难通。不宜卖买，互见相攻。"  
→ 六合为财婚和合之神，入空彼此不合而相攻，财难求，婚不成。  
  
"六合作鬼，入于空亡，文词为美，亦宜自防。"  
→ 文词虽美，入空须慎，谨防暗算。  
  
要点：六合空→婚约不成，交易不成。

### 勾陈入空

"勾入于空，官无讼凶。在外莫见，在后莫容。"  
→ 勾陈争斗之神，入空讼事无，但外见有勾引，末传后有余祸。  
  
"勾陈作鬼，入于空亡，内勾外连，尤防其殃。"  
→ 入空虽凶减，仍有内外勾连之祸，须防殃尾。  
  
要点：勾陈空→纠纷可解，但仍防余祸。

### 青龙入空

"龙入于空，仍作我妻。我妻见伤，难再言归。"  
→ 青龙乘德入空则伤妻，妻者干支上神合也。  
  
"龙入于空，仍作我财，一半可得，一半可谐。"  
→ 龙乃财喜之神，空则财可半得，不能全获。  
  
"龙入于空，仍作我官。志虽慕贵，不得成欢。"  
→ 龙乃官贵之神，入空官爵难得。  
  
要点：青龙入空→财喜减半，妻财受损。

### 天空入空

"天空入空，又休又刑，婚姻虚喜，终见无成。"  
→ 天空本主虚诈，再入空亡，婚姻虚喜，终无成。  
  
"天空入空，诸事无踪。吉不作吉，凶不作凶。"  
→ 凡劫煞凶神加天空入空，俱有影无形，凶吉皆不成。  
  
"天空作鬼，入于空亡，尤防暗损，诸事微茫。"  
→ 空鬼天空，暗中损耗，诸事无着。

### 白虎入空

"白虎入空，见凶不凶，宜于出往，反得其功。"  
→ 白虎凶将入空，凶减，且末传得吉将，反得其功，可任意出外。  
  
"支是天空，行人信通。带喜尤妙，不宜入空。"  
→ 天空加支上有外信入家，若入空则不以信论。  
  
要点：白虎入空→见凶不凶，是六壬中最大的减灾。

### 玄武·太阴·天后入空

玄武入空：  
→ 盗贼之神入空，谋害不成，失窃追寻有望。  
  
太阴入空：  
→ 阴私隐匿之神入空，暗事不成，私谋落空。  
  
天后入空：  
→ 婚姻妇女之神入空，妇人事不顺，孕育有阻。  
  
综合：三将皆主阴暗，入空则阴事更加虚渺，减力最明显。

### 发用空鬼综合断

"空亡作鬼带马丁，有人逃出事忙忙。"  
→ 空鬼带丁马，必有人逃出，或主离乡过继。  
  
"空亡克日却无依，孤单冷淡过生时。"  
→ 发用空鬼，主人无依，单冷度日。  
  
"用见其妻，复入于空，半路断弦，何日续终？"  
→ 发用见妻财，传入空，主断弦难续。  
  
断法要领：空鬼入传→事虽起，终无成；末传得实→可救，仍有一线。

### 回传入空与冲空

回传入空：  
→ 末传入空：虎头蛇尾，始有终无，事不完结。  
→ 中传入空：事中受阻，转机落空。  
→ 初传入空：事无头绪，虚头起手。  
  
冲空得实：  
→ 空亡之支被冲→反而得实，事可成。  
古诀："空亡逢冲，反为得实，不以空断。"  
  
应用：见空先看有无冲神，有冲则不作空论。
