# 取用神 · 六亲类神

> **这是什么**：读案例的第一把钥匙：先分清占的是谁、什么事，再定用神。
> ⚠️ **迁自旧版「六壬神课」App（2026-10-22 旧版退役时整体收入）**，原文照录、未逐条标页码；文中的「本站」「App」都指旧版。与第 7、12 课重复，**以课文为准**。

---

读案例的第一把钥匙：先分清"占的是谁、什么事"，再定**用神**。九宗门辨的是"课体"，这里定的是"用神"——把课盘落到具体问题上。源：飘《大六壬通解》上册·六亲与遁干、中册·类神系统。

一、六亲总纲（以日干为"我"，按五行生克认名分）

| 关系 | 六亲 | 常主人事 |
|---|---|---|
| 生我者 | 父母 | 庇护、文书、房宅、长辈、师长 |
| 我生者 | 子孙 | 子女、下属、医药、僧道、六畜 |
| 克我者 | 官鬼 | 官职、官司、疾患、盗贼、丈夫 |
| 我克者 | 妻财 | 钱财、妻妾、食物、田产 |
| 同我者 | 兄弟 | 兄弟、朋友、同辈、竞争、破财 |

※ 六亲定"名分"；占具体人事，还须并看下列"人事类神"与所乘天将。

二、人之类神（占某人，取谁）

| 占谁 | 取用类神 |
|---|---|
| 父母 | 生气爻、日干本气；父兼日德，母兼天后 |
| 妻 | 天后、财爻、神后（子） |
| 兄弟姊妹 | 太阴，兼兄弟爻 |
| 子孙 | 六合、子孙爻，太冲（卯）、登明（亥） |
| 奴仆 | 河魁（戌）、天空 |
| 婢女 | 从魁（酉）、太阴 |
| 朋友 | 六合 |

【原文】父母生气与日本，父兼德神母天后。妻责天后并财爻，神后之神亦为取。兄弟姊妹责太阴，及兼兄弟之爻神。子孙六合子孙爻，太冲登明亦可寻。奴责河魁及天空，婢责从魁太阴中。朋友单来责六合，以上人之类神从。

三、事之类神（占某事，取谁）

| 占何事 | 取用类神 |
|---|---|
| 求官职 | 青龙、太常，兼官星（官鬼爻） |
| 求名·文书 | 文书爻、朱雀 |
| 谒见·干贵 | 贵人 |
| 婚姻 | 天后（兼六合为媒） |
| 求财 | 青龙、财爻 |
| 衣服酒食 | 太常 |
| 占雨 / 占晴 | 青龙 / 天空 |
| 田土 / 道路 | 勾陈 / 白虎 |

【原文】求官龙常及官星，求名文书朱雀中。干贵贵人婚天后，求财青龙财交通。衣服酒食责太常，雨责青龙晴天空。田土勾陈路白虎，以上事之类神名。

四、取用方法（歌诀断法·最关键）

| 情形 | 如何取用 |
|---|---|
| 类神有二三 | 优先取已入三传/四课者为用神 |
| 皆入或皆不入 | 不用兼神，直取本将（如占妻只取天后） |
| 不在课传 | 为"局外"，看所临地盘定原因 |
| 用神旺衰 | 有气虽远可成、无气难；旺相德合终可亲 |

【原文】人事类神兼二三，以入传课为取用。若是皆入皆不入，不用兼神责将神。如妻止去责天后，财爻神后不须论。不在课传为局外，所临地位看原因。有气亦远无气难，旺相德合终可亲。
