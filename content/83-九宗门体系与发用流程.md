判断流程（按顺序逐步检查）

1

**先看是否特殊课型**

 · 日干支同宫（八专五日：甲寅、庚申、丁未、己未、癸丑）→ 四课变两课 → 八专课

 · 月将 = 占时支 → 天地盘完全重合 → 伏吟课

 · 天地盘各居对冲（子午换位…） → 返吟课

2

**四课有直接克吗？**（上下神五行相克）

 · 只有1处「上克下」，无下克上 → 元首课

 · 只有1处「下克上」，无上克下 → 重审课

 · 多处克，且都是同方向（全上克下 or 全下克上）→ 知一课

 · 既有上克下，又有下克上（混合）→ 涉害课

3

**无直接克 → 四课完整（没有重复）？**

 · 有「上神克日干」或「日干克上神」→ 遥克课

 · 完全没有遥克 → 昴星课（取地盘酉位上神）

4

**四课有重复（实为三课）？**

 · 无克无遥克，且四课中出现重复 → 别责课

九宗门详解 · 含课名由来

每张课体卡展开后的第一块，就是“为什么叫这个名字”。为什么九宗门下面有十个课名？因为第一宗“贼克法”分成**元首、重审**两种基本课体；二者合计仍只算一宗。

元首课

有克 · 唯一上克下

为什么叫“元首”

**元**是第一、根本，**首**是首领。此课只有一处上克下，上者独一无二地取得发用权，如君长居上而制下；同时它又列九宗之元、六十四课之首，所以称“元首”。

盘面对应：唯一的上克下 → 上神像首领一样直接发用。不要只把它记成“第一课”，重点是“上有唯一主令”。

**判断：**四课中只有一处「上神克下神」，没有下克上

**取法：**那个克处的上神就是初传；中传=初传落地盘上的天盘；末传同理

**象意：**上克下如君令臣，顺正之象，事多顺遂

记：唯一一个上神胜出，当仁不让发用

📐 推导步骤

第①步：逐格检查四课（四格），看每格上神与下神的五行是否相克（木克土、土克水、水克火、火克金、金克木）

第②步：找到唯一一处「上神五行 → 克 → 下神五行」，确认其余三格均无下克上

第③步：取该格的上神直接作初传

第④步：中传 = 查初传在地盘的位置 → 看该位置天盘是什么地支；末传同理再推一步

💡 **举例**：四课第一格「午（上）/ 子（下）」，午火克子水 = 上克下，且其他格无克 → **元首课**，初传 = 午

重审课

有克 · 唯一下克上

为什么叫“重审”

**重审**就是重新、慎重审察。正常秩序是上制下，此课却是唯一一处下贼上，如臣下犯上、卑者制尊，属于反常关系，不能按通常情形轻断，必须再加详审，故名“重审”。

盘面对应：唯一的下克上 → 矛盾由下方发动。记成“下犯上，须重审”。

**判断：**四课中只有一处「下神克上神」，没有上克下

**取法：**那个克处的下神为初传；若下神是天干（日干），取日干寄宫地支

**象意：**臣克君，需重新审视，事多反复、情况复杂

记：下神爬上来发用，事情有点反常

📐 推导步骤

第①步：逐格检查四课，找到「下神五行 → 克 → 上神五行」的格（即下克上）

第②步：确认全部四课中没有任何「上克下」（有则须用涉害法）

第③步：取该格的下神为初传；若下神是天干（日干本身），则取日干的寄宫地支代替

第④步：中末传照常从地盘天盘顺推

💡 **举例**：第三课「丁（上·火）/ 亥（下·水）」，亥水克丁火 = 下克上，且无上克下 → **重审课**，初传 = 亥

知一课

有克 · 多处同类克

为什么叫“知一”

四课出现两个或多个同向克时，候选不止一个，必须用“比用”比较候选阴阳是否与日干同类，最后从多者中**知其一、择其一**。名称强调的不是“只有一克”，而是“多项并见，比较后归于一用”。

盘面对应：多处同类克 → 先比阴阳，再定唯一初传。记成“多中知一”。

**判断：**四课中有多处「上克下」（无下克上），或多处「下克上」（无上克下）

**取法（上克下多处）：**阳日取第一课上神（干上），阴日取第三课上神（支上）

**取法（下克上多处）：**阳日取第一课下神，阴日取第三课下神

阳日：甲丙戊庚壬；阴日：乙丁己辛癸

记：多中取一，阳干跟着日干走，阴日跟着日支走

📐 推导步骤（比用法）

第①步：确认四课有多处克，且方向相同（全是上克下，或全是下克上）

第②步：判断日干阴阳：甲丙戊庚壬 = 阳日；乙丁己辛癸 = 阴日

第③步：阳日 → 多个候选中取属阳的地支（子寅辰午申戌）；阴日 → 取属阴的地支（丑卯巳未酉亥）

第④步：筛选后若仅剩一个 → 即为初传；若仍有多个同阴同阳，进入涉害法

💡 **举例**：壬日（阳），两处上克下，候选上神为「午（阳·火）」和「卯（阴·木）」→ 壬日取阳地支 → 初传 = 午（卯阴被淘汰）

涉害课

有克 · 上下混合克

为什么叫“涉害”

**涉**是行走、经历，**害**是沿途所受的克害。比用以后仍有多个候选，就把每个候选放回地盘本位，考察它到所临之位一路“涉历”多少克害；涉害较深者，矛盾积累更重，优先发用，故名“涉害”。

盘面对应：候选都像赶路者 → 比谁沿途经历的克害更深。这里的“害”不是只看六害，而是计算五行克制的层次。

**判断：**四课中既有「上克下」又有「下克上」（或知一相等无法直接取）

**取法：**从各克处出发，沿地盘顺序往前数，统计路途经过多少「被克地支」，经过克最多的那条路的起点上神为初传

**深浅规则：**孟（寅申巳亥）> 仲（子午卯酉）> 季（辰戌丑未），深者优先

**相等时：**见机格（孟上神）> 察微格（仲上神），或阳日取干上/阴日取支上

记：走得越远、克得越多，说明你涉险越深，取最深那条路

📐 推导步骤（涉害法是九宗门中最复杂的，耐心看完）

第①步：四课中**既有上克下又有下克上**（混合克），或比用法后仍有多个同阴同阳候选无法取舍

第②步：列出所有参与克的候选上神（上克下取上神，下克上取下神）

第③步：判断各候选在地盘的「位置类型」（这决定了"涉害深度"）：

 　　孟位（寅申巳亥）= 涉害最深 — 离老家最远，路途最长，遭遇克制最多

 　　仲位（子午卯酉）= 涉害居中

 　　季位（辰戌丑未）= 涉害最浅 — 离老家最近，经历最少

第④步：取涉害最深的候选为初传（孟 > 仲 > 季）　**〔《大全》口径〕**

⚠️ **另一说**：《大六壬通解》的「深」不是看地盘位，而是**把候选放回本家、沿途数被克的重数**，重数相等才论孟仲季。本站按《大全》，「六壬课程」教材按《通解》，同一张盘可能差一位。

第⑤步：若多个候选涉害深度相等（均在孟位，或均在仲位），用**复等格**：阳日取干上神（第一课），阴日取辰上神（第三课）

 　　注：见机格=取孟位者发用；察微格=取仲位者发用——均已在第④步"孟>仲>季"的深度比较中体现

💡 **为何孟位最深？**把每个候选想象成从"老家"（本宫）出发旅行的人——寅申巳亥（孟）路途最长，沿途遇到被五行克制的地方最多，所以"涉害"最深，动能最大，最有资格发用。

 **举例①**：混克候选有「寅（孟，第一课）」和「辰（季，第三课）」→ 孟 > 季 → 初传 = 寅

 **举例②（平局）**：候选「寅（孟，第一课·日干上）」和「申（孟，第三课·日支上）」→ 同是孟、深度相等 → 复等格 → 阳日取干上神 = 寅 → 初传 = 寅

遥克课

无克 · 日干与上神隔空克

为什么叫“遥克”

**遥**就是隔远。四课各自上下并没有贴身相克，只能越过本课上下关系，改查日干与其他课上神之间的克制，像双方隔空射击，所以叫“遥克”。蒿矢、弹射之名也都取“远射”之象，表示其力通常比直接贼克轻。

盘面对应：课内没有近克 → 日干与远处上神发生克。记成“近处不打，隔空相克”。

**判断：**四课上下神之间无直接克，但日干与第2/3/4课上神之间存在克

**蒿矢（上神克日干）：**「上神主动打日干」→ 取那个上神为初传，优先

**弹射（日干克上神）：**「日干打出去」→ 取被克的上神为初传

**多处遥克：**按知一/涉害的比用法处理

记：没打到面前，隔空喊话——蒿矢是被人打，弹射是自己射出去

📐 推导步骤

第①步：先确认四课上下之间**无任何正克**（每课上下五行相生、比和或无关系）

第②步：取出日干的五行属性（甲乙=木 · 丙丁=火 · 戊己=土 · 庚辛=金 · 壬癸=水）

第③步：逐一对照**第二、三、四课**的上神（天盘地支）五行：

 　　□ 若上神五行 → 克 → 日干五行 → 标记为「蒿矢候选」（外力来打我）

 　　□ 若日干五行 → 克 → 上神五行 → 标记为「弹射候选」（我主动出击）

 　　□ 注意：**第一课上神不参与**，它是日干的直接上神，属正克范围

第④步：优先取蒿矢（被打更紧迫）；若无蒿矢，则取弹射。取对应上神为初传

第⑤步：若多处同类遥克，再按比用法（阴阳相比）筛一次

💡 **蒿矢举例**：甲日（木），四课无正克。检查2/3/4课上神：第三课上神 = 申（金），金克木 = 申克甲日干 → **蒿矢格**，初传 = 申

 **弹射举例**：甲日（木），无蒿矢候选。第二课上神 = 未（土），木克土 = 甲克未 → **弹射格**，初传 = 未

 **联想记忆**：蒿矢 = 用芦苇秆射我（力量弱，伤害轻，但主动攻我）；弹射 = 我用泥弹打出去（主动出击，力也不强）

昴星课

无克无遥克 · 四课完整

为什么叫“昴星”

**昴**是二十八宿之一，属西方白虎七宿，位置系于酉宫；酉又名“从魁”。四课无正克、无遥克而又四课俱全时，便从酉位取用，借西方金气的肃杀、决断来启动三传，因此以所取星宿命名为“昴星”。

盘面对应：所有克都找不到 → 到酉位借昴宿之气发用。名字直接提示了取用坐标“酉”。

**判断：**四课（完整）既无直接克，也无遥克

**取法：**取地盘酉位上的天盘地支为初传（酉=从魁，昴星宿所在）

**刚日（阳干）：**从酉上取，祸从外起；**柔日（阴干）：**从酉上取，祸从内起

**象意：**四课死气沉沉，让西方肃杀之神出面决断

记：实在没得选，就让酉位（从魁）出来担大旗

📐 推导步骤

第①步：逐一核查——四课无正克（上下不克）→ 遥克也没有（日干与各课上神不克）→ 方才启用昴星法

第②步：在地盘上定位「酉」的固定位置（地盘各支永远不动，酉就是正西方那格）

第③步：看天盘中，位于「地盘酉位」正上方的地支 → 即为初传

第④步：中末传照常从天地盘顺推

💡 **为何取酉？**昴星宿（二十八宿）居于西方酉位，象征肃杀决断之气。四课死寂无克，系统被迫借西方金气强行启动三传。

 **举例**：当前天地盘中，地盘酉位正上方的天盘地支是「午」→ 昴星课，初传 = 午

别责课

无克无遥克 · 三课（四课有重复）

为什么叫“别责”

**别**是另外、另寻，**责**是求取、责取。此时四课不全，只剩三课，又无正克和遥克，不能照昴星法取用，只好离开现成三课，另外向干合或支合之神“责取”一个初传，故名“别责”。

盘面对应：三课不备、课内无用 → 向合神另借一路。记成“本处无从负责，别处求责”。

**判断：**四课中有重复（实际只有三课），且无克无遥克

**阳日取法：**找日干的天干六合地支（甲合己→找己所在支/乙合庚→找庚所在支…），取该地支天盘为初传

**阴日取法：**找日支三合局的中间一支（如日支巳→巳酉丑三合，取酉），取其地盘地支为初传；中末传取干上神

六合：甲己·乙庚·丙辛·丁壬·戊癸；三合：寅午戌·申子辰·巳酉丑·亥卯未

记：四课残缺，靠「合」字来牵线找初传

📐 推导步骤

第①步：确认四课有重复（如第一课=第三课），实际只有三课，且无克、无遥克

第②步（阳日）：

 　　① 找日干的「天干六合」对应天干（甲→己·乙→庚·丙→辛·丁→壬·戊→癸）

 　　② 找该天干的「寄宫地支」（甲→寅·乙→辰·丙→巳·丁→未·戊→巳·己→未·庚→申·辛→戌·壬→亥·癸→丑）

 　　③ 看地盘该寄宫位置上的天盘地支 → 初传

第③步（阴日）：

 　　① 找日支所在「三合局」（寅午戌·申子辰·巳酉丑·亥卯未）

 　　② 取三合局中居中的那支（寅午戌→午；申子辰→子；巳酉丑→酉；亥卯未→卯）

 　　③ 看地盘该地支位置上的天盘地支 → 初传

第④步：中传和末传均取日上神（固定，不再推演）

💡 **阳日举例**：丙日（阳），丙合辛，辛寄宫戌 → 查地盘戌位天盘 = X → 初传 = X，中末传 = 丙上神

 **阴日举例**：丁日（阴），日支亥 → 亥卯未三合，居中是卯 → 查地盘卯位天盘 = X → 初传 = X，中末传 = 丁上神

八专课

特殊 · 干支同宫，两课

为什么叫“八专”

**传统释名：**古法解释“四课八字”——四课每课有上下，共八个字；八专时干支阴阳之神重叠在同一处，好比**八家共用一井，众意专聚一处**，所以称“八专”。

**结构理解：**十干寄宫只落在寅、辰、巳、未、申、戌、亥、丑八个位置，子午卯酉四正位没有天干寄宫，因此干支同位只能从这八个非四正位置中产生。这可以帮助理解“八”字，但属于结构性解释，古籍直接采用的仍是“八家同井、专聚一处”。

**不要误会：**“八”不表示有八个八专日。受干支阴阳配合限制，六十甲子中实际只有甲寅、庚申、丁未、己未、癸丑五日。

盘面对应：四课八字高度重合，实质只剩两课 → “八字共处、专聚不分”。记忆时可并用两条线索：古义看“八家同井”，结构看“八个非四正寄宫位”。

**判断：**日干寄宫与日支同一地支（八专五日：甲寅、庚申、丁未、己未、癸丑），四课中第一二课相同、第三四课相同，实为两课

**有克：**仍按贼克法（元首/重审/涉害）取初传

**无克：**阳日从日上神顺数3位取初传；阴日从支上神逆数3位取初传

**中末传：**均取日上神（不管有没有克）

**象意：**干支混杂同位，阴阳不分，主私秘淫乱、事情不清

记：两课局面，没克就顺（阳）逆（阴）数三个找初传

📐 推导步骤

第①步：确认日干寄宫地支 = 日支（如甲寄寅·乙寄辰·庚寄申·辛寄戌·壬寄亥·癸寄丑等），四课因此只剩两课有效

第②步：检查这两课是否有克（上克下或下克上）

 　　**有克** → 按贼克法（元首/重审）正常取初传；中末传均取日上神（固定）

第③步（无克·阳日）：从日上神地支出发，**顺时针数3位**（子→丑→寅→卯方向）→ 到达的地支为初传

第④步（无克·阴日）：从支上神地支出发，**逆时针数3位**（卯→寅→丑→子方向）→ 到达的地支为初传

第⑤步：中传 = 日上神，末传 = 日上神（中末均同，固定为日上神）

💡 **举例（无克·阳日）**：甲寅日（阳），日上神 = 午

 顺时针数3位：午→未(1)→申(2)→酉(3) → 初传 = 酉

 中传 = 午（日上神），末传 = 午（日上神）

伏吟课

特殊 · 天地盘完全重合

为什么叫“伏吟”

**伏**是伏藏不动，**吟**是受困而低吟。月将加在同一占时上，天地盘十二支各归本宫、上下重合，整个盘面没有位移，诸神像伏在原处不能行动，只能隐伏呻吟，故名“伏吟”。

盘面对应：天盘不转、各支伏在本位 → 静极难动；因此三传常借“刑”强行推动。

**判断：**月将 = 占时支，天地盘各支都在本位（子还在子，丑还在丑…）

**有克：**按贼克法取初传；中传=初传所刑，末传=中传所刑

**无克：**阳日取日上神，阴日取支上神为初传；中末依刑推

**刑序：**寅刑巳→巳刑申→申刑寅；丑刑戌→戌刑未→未刑丑；子刑卯→卯刑子；辰午酉亥**自刑**（遇自刑则取日辰并用）

**象意：**万物潜伏不动，主隐匿、事不明、静中难动

记：天地合体不动，只能靠「刑」来撬动三传

📐 推导步骤

第①步：确认月将 = 占时地支（如月将午、占时也是午时）→ 天地盘完全重合，各支都回到本位

第②步：检查四课是否有克

 　　**有克** → 按贼克法（元首/重审）取初传；但中末传须改用刑法（见第④步）

第③步（无克时）：阳日取干上神（第一课上神）为初传；阴日取支上神（第三课上神）为初传

第④步：用刑序推中末传（初传刑→中传；中传刑→末传）：

 　　寅→巳→申→寅（三角循环）

 　　丑→戌→未→丑（三角循环）

 　　子→卯→子（对刑循环）

 　　辰·午·酉·亥 = 自刑（自己刑自己，此时取日干上神与支上神并用为杜传）

💡 **举例（无克·阳日）**：庚申日，月将申·占时申时 → 伏吟！

 庚寄宫申，干上神 = 申（天地盘重合时，申位上的天盘也是申）

 初传 = 申 → 申刑寅 → 中传 = 寅 → 寅刑巳 → 末传 = 巳

 **为何用刑？**天地盘冻结，一切静止，只有「刑」这种强制撕裂的力量才能打破静止，撬动三传流转。

返吟课

特殊 · 天地盘各居对冲

为什么叫“返吟”

**返**是返回、反转，**吟**仍有不安呻吟之意。月将与占时相冲时，天地盘十二支全部临到自己的对冲位置；上下相反，三传又常在冲位之间往返，所以叫“返吟”，也常写作“反吟”。

盘面对应：伏吟是“原地不动”，返吟是“全盘翻到对面”；一静一反，正好成对记忆。

**判断：**天地盘各支居于对冲位（子在午位、午在子位……十二支全部如此）

**有克：**按贼克/涉害法取初传；中传=初传冲位，末传=中传冲位（即回到初传）

**无克（井栏射，丁己辛+丑未日）：**取支上神所刑地支为初传；中传=初传冲，末传=中传刑

**象意：**来去相冲，反复无常，主事情不定、往返变化

记：天地对冲，三传也跟着「冲来冲去」反复

📐 推导步骤

第①步：确认月将与占时相冲（如月将子·占时午时，子午相冲）→ 天盘与地盘各支全部对调到冲位

第②步：检查四课是否有克

 　　**有克** → 按贼克/涉害法正常取初传（方法同前）

第③步（有克时）中末传固定公式：

 　　中传 = 初传的冲位地支（子冲午·丑冲未·寅冲申·卯冲酉·辰冲戌·巳冲亥）

 　　末传 = 中传的冲位 → 又回到初传对面，来回反复

第④步（无克时·井栏射）：仅限丁己辛日+丑未时出现

 　　取支上神所刑之地支为初传；中传 = 初传冲；末传 = 中传刑

💡 **举例（有克）**：壬日，返吟课，克取法得初传 = 午

 中传 = 午冲 = 子 → 末传 = 子冲 = 午（又回来了！）

 三传：午→子→午，来回横跳 → 这正是"返吟"反复无常的象意

 **记忆口诀**：返吟三传冲来冲去，事情就像乒乓球，一来一回定不了

第一步 · 优先检查特殊课型

以下三类最先判定，任一符合即确定宗门

**月将 = 占时**（天地盘完全重合）→ 伏吟课

 有克→克贼法；无克→阳日刑干上神（自任格），阴日刑支上神（自信格）；所取自刑→杜传格

**月将与占时地支相冲**（天地盘对冲）→ 返吟课

 有克→克贼法；无克→取日干**驿马**发用；丁己辛丑未日→**井栏射格**

**日干寄宫 = 日支**（干支同位，仅两课）→ 八专课

 有克→克贼/涉害；无克→阳日顺数3位，阴日逆数3位；中末传均取**日干上神**

↓ 均不符合，继续向下

第二步 · 四课有无正克

四课中存在下克上（贼）或上克下（克）？

⭐ **只一处上克下，无贼克** → 元首课

 取上克下之**上神**为初传，三传相因

⭐ **只一处下克上，无正克** → 重审课

 取下克上之**上神**（受克之神）为初传，三传相因

**多处同向克，取阴阳与日干相同者** → 知一课（比用法）

 多贼中比阴阳；多克中比阴阳　仍多个 → 进涉害

**贼克正克混存 / 多克阴阳不比** → 涉害课

 各克路顺数至本家，克害最多（最深）者发用

 相等→取**四孟**（见机格）→无孟取**四仲**（察微格）→再等→阳取干上/阴取支上（复等格）

↓ 四课上下全无克

第三步 · 无克时依次检查

**日干与第2、3、4课上神有遥克（斜向相克）** → 遥克课

 上神遥克日干 → **蒿矢格**（取遥克日干之上神为初传）

 日干遥克上神 → **弹射格**（取被日干遥克之上神为初传）

 两处遥克 → 取阴阳与日干相比者

**无遥克 + 四课完备（无重复）** → 昴星课

 取**酉宫**（从魁）上神为初传，不分阴阳日（刚日祸从外，柔日祸从内）

**无遥克 + 四课不备（有重复＝三课）** → 别责课

 阳日→取日干六合天干寄宫地支上神；阴日→取日支三合居中那支（帝旺位）上神

 中末传均取**日干上神**（不相因）

九宗门逐门详解（点击展开）

一

元首课

上克下 · 天象

条件四课中**只一处上克下**，无任何下克上

初传取上克下的**上神**为初传发用

中末传相因法（通用）

元首一上克其下，天地得位品物亨。

如君驭臣，名正言顺，九宗之首。

象意事从外来，名分正当，顺势而为，主吉。占官升迁主顺，占财主得，占行人主来。

二

重审课

下克上 · 地象

条件四课中**只一处下克上（贼）**，无任何上克下

初传取"下克上"的**上神**（受克之神）为初传

中末传相因法（通用）

重审一下贼乎上，以臣净君详审行。

臣逼君，须反复审查，慎防逆乱内情。

象意事从内起，情况复杂，有逆上之意，内有隐情。宜谨慎审查，防小人从内为害。

三

知一课

比用法 · 从专

条件多处同向克（全贼或全克），需以阴阳比用区分

初传多克中取与**日干阴阳相同**者

阳日取阳神（子寅辰午申戌）；阴日取阴神（丑卯巳未酉亥）

仍多个同比者仍有多个 → 进入涉害法

中末传相因法（通用）

知一上下二相克，择比而用允执中。

知一不知其余，得一则万事定。

象意专一守中，决断清晰。宜集中力量于一处，分散则不成。

四

涉害课

路途深浅 · 归本家

条件多克且阴阳不比，或贼克正克同时存在

起传各克处上神顺数至本家，途经地支若克该神则计"害"，**害数最多（最深）者**发用

涉害由来是本家，路途多克最堪夸。

孟深仲浅季无取，复寻柔辰刚日查。

见机格深浅相等→取**四孟**（寅申巳亥）上神。见机则不俟终日，时机贵速。

察微格无四孟→取**四仲**（子午卯酉）上神。忧虑防范，察其细微。

复等格仍相等→阳日取**日干上神**，阴日取**日支上神**发用

象意路途险阻，危中有机。见机识时，取最利处突围。

五

遥克课

无正克 · 斜向相克

条件四课无正克，但日干五行与第2、3、4课上神五行存在相克

蒿矢格**上神遥克日干** → 取该上神为初传

主初声势大后力衰，利速不利久

弹射格**日干遥克上神** → 取被克上神为初传

主利客（先动者）不利主（静守），宜先发制人

两克遥克有两处时，取阴阳与日干相比者

中末传相因法（通用）

阴阳上下无相克，其中择取遥相贼。

贼日之神为用神，弃日之克切需知。

六

昴星课

无克无遥 · 从魁酉宫

条件四课**无正克、无遥克**，且四课完备（无重复）

阳日取**酉宫**（从魁）天盘上神发用

虎视转蓬：祸从外来，家居守静则吉

阴日取**酉宫**（从魁）天盘上神发用（与阳日同）

阴伏掩目：祸从内起，行者淹滞，逃亡可匿

中末传相因法（通用）

四课既无克而复无遥，则为昴星。

酉中昴宿，白虎金位，性主刑杀，义司决断。

象意事情晦暗难明，不宜轻动冒进。访人不见，谋事受阻，占出行不吉。

七

别责课

三课不备 · 芜淫

条件四课**有重复**（实为三课），且无正克无遥克

阳日初传取日干六合天干的寄宫地支上神

甲己→未；乙庚→辰；丙辛→戌；丁壬→未；戊癸→丑

阴日初传取日支三合局居中那支（帝旺位）上神

寅午戌→午；申子辰→子；巳酉丑→酉；亥卯未→卯

中末传**均取日干上神**（不相因，与通用规则不同）

别责无克三课备，刚三柔六九为中。

四课不备，阴阳不全，芜淫肆意。

象意事体不全，所谋难以完整实现，占事多有缺陷，利守不利进。

八

八专课

干支同位 · 仅两课

条件日干寄宫地支 = 日支（干支同位），四课实为两课

常见：甲寅、乙辰、丙巳、戊巳、丁未、己未、庚申、辛戌、壬亥、癸丑

有克时按克贼法或涉害法取用（不取遥克）

无克·阳日从**日干上神**起，天盘**顺数3位**为初传

无克·阴日从**日支上神**起，天盘**逆数3位**为初传

中末传**均取日干上神**（不相因）

两课无克号八专，无克顺逆数三神行。

刚顺阴逆，中末日上合天心。

独足格三传均归日干上神（如己未日癸酉时）。主移动艰难，诸占不吉，病占主死。

象意奸邪惊怪，事体混杂。专而有余，难以全面顾及。

九甲

伏吟课

天地盘重合 · 潜伏静

条件月将 = 占时（天地盘完全重合，十二支各居本宫）

有克时按克贼法正常取用，三传相因

无克·阳日

自任格取**日干上神**为初传；中传=干上神所刑，末传=中传所刑（三刑相因）

三刑：寅→巳→申→寅；丑→戌→未→丑；子→卯→子；辰午酉亥自刑

无克·阴日

自信格取**日支上神**为初传；中末传同样以三刑相因

中末传初传所刑为中传，中传所刑为末传（三刑相因）

杜传格初传为自刑（辰午酉亥），三传同一神，主事中途而止，堵塞不通

伏吟天地俱不动，无克刚看日上柔取辰。

万物潜伏，屈而不伸，主静迟阻滞。

象意主静迟、内阻、隐患潜伏，动则愈滞。自任宜守静，自信家宅不宁。

九乙

返吟课

天地盘对冲 · 反复动

条件月将与占时地支相冲（天地盘完全对冲，十二支均居对宫）

有克时按克贼法正常取用，三传相因

无克初传取**日支上神所刑地支**为初传

三刑：寅→巳；巳→申；申→寅；丑→戌；戌→未；未→丑；子→卯；卯→子

无克中末中传 = 初传所冲；末传 = 中传所刑

井栏射格丁、己、辛、丑、未日无克 → 井栏射格（起法同上）

返吟有克往来取，井栏丑未丁己辛。

天地俱返，往来不定，主动荡反复速变。

无依格阳日无克 → 祸从外来，动荡不安

无亲格阴日无克 → 速成易破，内外失调

对比伏吟伏吟主静主内（潜伏）；返吟主动主外（反复）。阴阳对立，一藏一显。

九宗门总口诀
