# 第13课 · 七处与八门：先看哪几个位置

> **本课解决什么**：盘上二三十个字，**从哪儿下嘴**。这一课把第 1 课提过的两个框架拆开讲透。
> **前置**：[[12-类神·占什么事看什么字]]
> **本课的一句话**：**七处是必查的七个位置，八门是每个位置的职守——先扫七处，再按门读事。**

---

## 一、七处：决断先看的七个位置

> 「所谓七处，一般指**日、辰、初传、中传、末传、本命、行年**，壬学决断**先看七处**，次看类神，以七处为关键……另外有一些壬学书讲八处……还有九处之说……**实际应用中，我们掌握七处即可**，其他在活断中可以斟酌而用。」
> 〔通解上 p79｜PDF p94〕

| 处 | 位置 | 管什么 |
|---|---|---|
| 1 | **日**（日干与干上神） | 我、我的外部处境 |
| 2 | **辰**（日支与支上神） | 家宅、对方、所占之物 |
| 3 | **初传** | 事情从哪儿发动 |
| 4 | **中传** | 中间的转折 |
| 5 | **末传** | 结果、归宿 |
| 6 | **本命** | 这个人的根本 |
| 7 | **行年** | 这个人当前的运程 |

> ⭐ **七处是"扫描线"**：拿到盘先把这七个位置各看一眼——**乘什么将、临什么宫、旺不旺、空不空、有没有刑冲破害**。扫完就知道该往哪儿细看。

---

## 二、八门：每个位置的职守

> 「正时为**先锋门**，天上直时将为**直事门**，日为**外事门**，辰为**内事门**，初传**发端门**，中传**移易门**，末传**归计门**，以人的本命行年为**变体门**。」
> 〔通解上 p137｜PDF p152〕

| 门 | 位置 | 象意 |
|---|---|---|
| **先锋门** | 正时（占时） | 事情的引子、来意——**课体未出，吉凶已露** |
| **直事门** | 时上天将 | 当下管事的那一位 |
| **外事门** | 日干 | 我、外面的事 |
| **内事门** | 日支 | 家宅、里面的事 |
| **发端门** | 初传 | 事起于何 |
| **移易门** | 中传 | 中间的转折 |
| **归计门** | 末传 | 结果、归宿 |
| **变体门** | 本命、行年 | 落到具体这个人身上 |

> 💡 **七处与八门是同一批位置的两种说法**：七处偏"查哪里"，八门偏"这里管什么"。八门比七处多出**正时**与**时上天将**两个——这正是六壬最看重的切入口。

---

## 三、⭐ 先锋门：从占时切进去

> 「**正时是课传的第一引发点**。因此在预测来意与事情的发展主线上，有重大的引导作用。**古法多以之占断来意**。」
> 〔通解上 p137｜PDF p152〕

判断正时，主要看**它与日干支的关系**：

| 正时的情形 | 断 |
|---|---|
| 时乘空亡 | 多为**虚诈** |
| 时为驿马 | 多主**改动迁移** |
| 时日同辰 | 多主**迟疑偃蹇** |
| 冲辰冲日 | **颠沛流离** |
| 时日相生 | 迭为恩泽 |
| 时为日之贵德禄 | 多为**官贵** |
| 时为劫杀 | 虽迅速而多属**颠危** |
| 时为日墓 | **坟冢、迟滞**之事 |
| 时干与日干合 | **外事和同** |
| 时支与日支合 | **婚姻和合** |

**十二支占时各有偏向**：

> 「**子午之时往来多变，卯酉之时多涉门户，辰、戌、丑、未土产墓基**。辰遇时刑，讼狱之祸；日逢时破，有走失之悲。」
> 〔通解上 p137｜PDF p152〕

---

## 四、发端门：初传最要紧

> 「所谓发用，就是初传，又名**发端门**，代表**矛盾的起点、事情的起点**，为**心之所主，事之所向，最为紧要**。」
> 〔通解上 p138｜PDF p153〕

### 发用的方向：谁受灾、利谁

> 「**用起上克下**，卑幼有灾，**事从外来**，占**利男子**，兵利先起。
> **用起下贼上**，尊长有厄，**事从内起**，占**利女人**，并**利后应**。」
> 〔通解上 p138｜PDF p153〕

| | 上克下发用 | 下贼上发用 |
|---|---|---|
| 谁有灾 | 卑幼 | 尊长 |
| 事从哪来 | **外来** | **内起** |
| 利谁 | 男子、先动 | 女人、后应 |

> ⭐ 这一条把第 5 课的"贼"与"克"从**取法**变成了**断法**——取三传时分贼克是为了定初传，到断课时它还告诉你**事情来自内还是外**。

### 发用的状态各主什么

| 发用 | 断 |
|---|---|
| 临**长生** | 所谋大遂 |
| 临**败** | 其事必败 |
| 入**墓** | 事缓、病死、物在、人归 |
| 刑冲破害日 | 身不安稳 |
| 为**驿马** | 事情有动态发展 |
| **空亡** | 捕风捉影 |
| 为**官鬼** | 事情有扰 |
| 为**父母** | 代表求谋 |
| 为**妻财** | 多与财利有关 |
| 为**子孙** | 子孙、晚辈、下级事 |
| 为**兄弟** | 兄弟朋友事，或阻力是非 |

〔通解上 p138｜PDF p153〕

### 发用直接定应期的粗档

> 「如果**初传为太岁**，就代表是**当年**发生的事情；发用为**月建**则**月内**应事；发用为**日辰**则**日内**应事；发用为**旬**则旬内应；发用为**候**则候内应，分为五段。」
> 〔通解上 p138｜PDF p153〕

举例：正月占事，发用**寅**（功曹，正月建）→ 当月应；发用**丑**（上一位）→ **事情已经过去**；发用**卯**（下一位）→ **将来发生**。〔通解上 p138｜PDF p153〕

> 💡 **过去 / 现在 / 未来，就看发用相对月建靠前还是靠后**——这是最快的一把时间尺。应期细法在第 16 课。

## 五、移易门与归计门

> 「所谓**移易门，就是中传**。代表事情的中间过程，因此有**转换**的含义，假如**初传凶而中传吉，那就代表转凶为吉**了。」
> 「所谓**归计门就是末传**。象征事体的**最后阶段以及结果**……占断事情的最后结果以及应期时，需要**结合课体结构而详细考察末传**。」
> 〔通解上 p139｜PDF p154〕

> ⭐ **三传就是事情的三段**：初传"从哪起"、中传"中间怎么变"、末传"落到哪"。
> 断课时先看这三段**各自的六亲与天将**，再看**它们之间的生克**（递生／递克），一条事情的走势就出来了。

## 六、一段发用歌诀（可当口袋清单）

原书列了一首"发用基本应用歌诀"，把上面这些收得很齐：

> 「**日主外兮辰主内**，四课各就日辰推。一二发用贵顺行，用在贵前事速成。三四发用天乙逆，用在贵后吉凶迟。四课发用名蓦逢，事主偶然或蓦成。
> **用上克下事外来，利男利先卑小灾。用下克上事起内，利女利后尊长悲。**……
> 用遭夹克名逼迫，身不自由受驱策。用克上下为隔将，隔断难合事不冒。
> **用起长生凡谋遂**，长生临墓发旧事。用败与死事坏毁，用绝事了人信至。**用墓事缓病者悲，物在人归凶事微。**
> 刑冲破害事隔阻，用空忧喜无实遮。**克日忧身长上讼，克辰家宅不安宁。克时心动惊忧起，克末有始必无终。克命上神主得财，克年上神事必乖。**」
> 〔通解上 p139｜PDF p154〕

> 💡 歌诀里「**用在贵前事速成，用在贵后吉凶迟**」是一条很好用的快判：**发用在天乙贵人前面（顺行方向）事快成，在后面则迟**。

---

## 七、⚠️ 四个坑

1. **跳过正时直接看三传。** 先锋门是"课体未出，吉凶已露"的那一步，**来意多半就在这里**。
2. **只看初传不看中末。** 初凶中吉可以转凶为吉；末传才是结果。
3. **忘了年命这一门。** 变体门把课落到具体这个人身上——**同一时辰不同人来占，全靠它分**。
4. **七处只扫一遍就下结论。** 七处是扫描，**类神落在七处的哪一处**才是重点（第 12 课）。

---

## 八、自测

**1.** 七处是哪七个？八门比七处多了哪两处？

**2.** 发用是上克下，事情从内来还是从外来？利男还是利女？

**3.** 正月占事，发用是丑，事情在什么时候？发用是卯呢？

**4.** 初传凶、中传吉，怎么断？

**5.** 「用在贵前」与「用在贵后」，差在哪？

---

### 答案

**1.** 七处＝**日、辰、初传、中传、末传、本命、行年**。八门多出**正时（先锋门）**与**时上天将（直事门）**。

**2.** **从外来**，**利男子**、利先动；同时主**卑幼有灾**。（反过来，下贼上是事从内起、利女人、利后应，尊长有厄。）

**3.** 正月建寅。发用**丑**在寅之前一位 → **事情已经过去**；发用**卯**在寅之后一位 → **将来发生**。发用正好是寅，则当月应。

**4.** **转凶为吉**——中传是移易门，代表事情的中间转换。但还要看末传（归计门）落在哪，结果以末传为准。

**5.** 发用在**天乙贵人前面**（顺行方向）主**事速成**；在贵人**后面**主**吉凶迟**。这是一条判迟速的快法。
